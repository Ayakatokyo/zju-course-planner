本轮对象是回环地址上的 **独立 synthetic 本人工作区、确定性计算及 Web 规划切片**。服务端验证的是项目预置 synthetic 主体及绑定，不能称作学校身份验证。学校认证、真实本人档案/学业数据源、RAG/Agent 和学校页面解析仍未接入；学校登录成功也不代表取得学业 API 或数据使用许可。

设计依据：[登录认证与权限设计](../docs/登录认证与权限设计_v1.md)、[数据结构与字段字典](../docs/数据结构与字段字典_v1.md)。设计中的“未实现/未执行”保留为形成设计时的历史状态；当前实现状态以本轮代码、实际验证记录及主任务更新为准。

## 证据与状态使用方式

- “synthetic 已验证部分”只指本轮已运行的用例和主任务实际观察过的本机页面切片，不扩展为真实学生或学校整体产品验收通过。
- Python 用例覆盖学业、导入、排课、应用、权限和 HTTP；Web 契约测试在 Node 中运行，不能替代浏览器验收。最终实际执行 129 项，完整日志及代码 SHA256 已固化；本映射不从测试数量推断产品整体验收完成。
- 主任务本轮实际页面已观察到基础学分 8、课堂学分 4、在修学分 3、1 项未知，原 23 条规则仍为待审核候选；JSON/CSV/ICS 已实际下载并核对冻结输入。下载摘要见 [浏览器下载核对](browser_downloads_20261009.json)，规划截图见 [规划页面截图](screenshots/planning_20261009.jpg)。这不能证明学校真实页面已适配。
- 来源完整性检查证明原 `inputs` 与清单/展开数据一致，不能证明候选规则官方有效或适用于真实学生。原 23 条候选和空真实教学班模板保持原样。
- 下表“尚未完成”同时包含真实数据依赖、尚未实现能力及尚未执行的验收；不能因为 synthetic 测试通过而统一改为完成。
