## 实际浏览器观察

继续使用 README 的本机服务 `python3 -m course_assistant.server --enable-mock --port 8765`、忽略的 `runtime/planning.sqlite3`，重新载入最终静态资源。仅操作固定合成 A/B 和公共交接资料。

| 操作 | 实际观察 |
| --- | --- |
| 登录 B | 默认选中 Agent 对话；原条件表单保留在条件与课表；发送按钮 disabled，显示模型待接入 |
| 点击示例、编辑草稿 | 示例填入需求输入框，允许编辑；没有模型消息或虚构理解结果 |

| 返回 Agent | 未发送草稿仍在本页面内存；刷新则清空 |

验收中发现并修正两项布局缺陷：单列 Grid 分配剩余高度让导航下出现空白；导航最小内容宽度撑大页面。修后按上述 DOM 宽度验证；临时视口已恢复默认。

当前工具设置的尺寸与实际 CSS 视口不同，最小得到 CSS 480px；**390px 未验收**，不把参数设置当证据。移动设备、所有尺寸、模型消息/流式回复等仍未覆盖。

## 结论

已实现并验证：对话主入口、需求草稿/示例、准确的未配置状态、独立手动预览及原计算辅助入口。尚未实现：自然语言理解、真实模型调用、多轮 Agent、对话持久化、受限模型工具包装和 RAG。外部 API 与本地模型都是拟议接入形式，具体选型未定。

本轮不扩大原八项及 A01–A10 的整体验收范围；学校真实认证、本人数据源和模型对话均需各自实现及证据。前轮下载、学业与复杂调整证据保留历史范围，详见[顺序 09 记录](验收记录_20261009.md)。本轮未提交、推送、打包、PR 或部署。
