本机配对码和连接token仅用于loopback任务通道，不是学校Cookie或可信身份；它们不写文件、CLI参数、业务数据或日志。扩展无cookies/storage/scripting权限，仅官方教务域与127.0.0.1。内存内容实例每5秒发心跳，20秒无活性使epoch失效；授权变化、断开、标签关闭/导航、失效、验证码和新个人承诺均阻断旧正文。页面导航需要重新确认来源与配对。

学校请求固定白名单路径来自已核对Celechron线索，且必须在当前实际页面路径、链接或表单观察到才可执行。学年/学期按来源select的显示标签核对目标范围，只使用其实际value，不猜秋冬编码。HTTP响应实测status/content-type、登录跳转、业务结构、行数和分页分别核验；不会把200登录HTML算成功。

## 培养方案按需获取

来源档案提供明确入学年或完整入学日期、学院、专业/类专业、项目和路径。入学日期可派生年份并保留来源，账号片段/当前年级不能替代。查询只面向这一适用范围；缺必要范围返回profile_fields_missing，不默认26级。目录未明确项目/路径继续保留未知；类专业与目录专业可作同名候选筛选，不能变已验证专业。

本轮沿实际学校菜单确认培养方案查询页及其公开页面脚本：目录按来源年级、学院和专业控件查询，PDF使用该脚本与实际预览页共同确认的固定资源接口。文档资源后缀为`.html`，因此校验实际PDF MIME和字节，不以文件名判断。教学计划号只来自窄范围返回的候选，随机plan_ref不接任意URL，不转发页面账号参数。目录表没有年级列；由已确认查询范围取得的年级保留`cohort_provenance=confirmed_query_scope`，不会冒充源行字段。通用DOM目录兼容分支仍明确`http_status:null`与`browser_dom`，不能称作HTTP目录实测。

得到0个候选返回plan_missing，多个返回ambiguous_plan；明确适用字段矛盾拒绝。一个候选可定向保存，但状态仍为acquired_pending_review、binding_status=not_verified、rules_status=not_reviewed。PDF的MIME、签名、EOF与10MiB限额核验只是传输完整性，不代替正文年级/路径审阅或可执行规则审核。

目录0700、PDF/JSON/锁文件0600；源PDF按内容摘要保存，元数据另有不可变版本和活动指针。相同授权范围重复获取复用已保存版本并标historical_cache；强制刷新产生新版本，旧版本保留。失败标历史，不将旧PDF声称本轮实时结果；撤销、到期或会话变化拒绝正文。通用方案来源与本人适用绑定仍分开，现26级资料作为原有版本保留。

## 本机使用

安装新编写的非商店扩展及授予教务页面访问权限需要浏览器工具的即时确认；代码和工程测试可以先完成。批准后按连接器说明加载该目录，在官方页面完成登录/验证码/必要确认并选择范围。不会把主应用的A/B切换为真实身份。

每次连接固定一个来源页，首片建议一次一个域。例如新建私有批次读取成绩：

```sh
python3 scripts/run_student_source_sync.py --root <local-only内新的私有批次目录> --term <实际来源目标学期> --operations academic
```

目标学期形式为`YYYY-YYYY-AW/SS/A/W/S/SU`，必须与来源控件显示范围一致。用`timetable`或`exams`分别启动对应来源任务；`major_academic`单独处理，不能和academic占同一个3页尝试。CLI显示loopback连接页地址，配对码只在本机页面输入扩展，不发送到聊天。连接准备默认60秒，可用`--wait-seconds 300`延长到5分钟；每请求30秒；超时明确停止，不能当完成。

用已有官方档案观察定向取得方案：

```sh
python3 scripts/run_student_source_sync.py --root <local-only内新的私有批次目录> --term <目标学期> --operations '' --plan-profile <private或local-only内的官方profile观察.json>
```

这里既有档案仅用于来源范围，不冒充本轮验证身份。`--force-plan`要求实际重新取得；已有任务可用`--attempt`在同一授权内接续。每次回执另存，原件和旧回执不覆盖。首次无扩展连接返回browser_not_connected；未确认路由/学期、目录列不适配或没有已确认的PDF资源引用，均需真实页面适配后才能验收。
