## 使用入口

```sh
python3 -m course_assistant.server --enable-school --port 18875
```

打开 http://127.0.0.1:18875/，在本机页面输入学校账号、密码，登录后进入“我的教务”。验证码由使用者输入；学校失效提示同账号重新登录。账号更换需先退出。本机服务只绑定127.0.0.1，关闭服务后学校会话清理。

默认运行库 `private/school_app/planning.sqlite3`；最小业务投影及培养 PDF 放在其下私有本人目录。所有这些材料被 Git 忽略，目录0700、文件0600；运行数据库可另指定项目外或项目 `private/`、`local-only/` 路径。页面和 API 不接收任意学生 ID、学校 URL、Cookie 或培养 PDF URL。

## Celechron 能力如何迁移

参考固定提交 [724e54a3 的本科教务客户端](https://github.com/Celechron/Celechron/blob/724e54a3d8feb190a90544963cd53e8ef01c0ff9/lib/http/zjuServices/zdbk.dart)，以 Python 标准库独立实现协议和请求映射，没有运行或嵌入上游 Flutter 应用。学校公开页面脚本及实际可见查询控件用于校准字段。

```mermaid
flowchart LR
    A[本机登录页] --> B[Python 学校客户端]
    B --> C[学校 CAS 验证]
    C --> D[教务会话]
    D --> E[已认证本人资料]
    E --> F[本人会话与权限]
    F --> G[成绩 课表 考试 培养 PDF]
    G --> H[本机本人资料页面]
```

| 模块 | 实际职责 |
| --- | --- |
| `school_http.py` | CAS表单/public key/RSA、SSO与教务Cookie、固定接口、响应验证、图片验证码、有限会话更新 |
| `school_accounts.py` | 学校返回的本人身份绑定、本机会话、同主体重登录、私有投影、查询与培养PDF编排 |
| `auth.py` / `server.py` | 独立学校客户端realm、回环登录与业务API、Host/Origin/CSRF、退出与晚到结果复核 |
| `student_source_client.py` / `student_source_parsers.py` | 既有分域解析、分页/完整性、代次、历史缓存、重复修读与缺值保留 |
| `student_plan_acquisition.py` | 当前本人范围查询、唯一候选判断、PDF完整性、不可变版本及本人下载 |
| `web/` | 本机账号表单、验证码/重登录、本人数据表格、按需方案和下载 |

密码只在本次表单处理和学校请求中暂时使用，不存数据库、文件、前端状态或日志。学校Cookie/票据只在客户端内存，不返回页面或导出。页面提交后清空密码；遇初次登录验证码需要重新输入密码，服务不保留密码等待验证码。

本机身份必须来自已认证的本人资料响应，不从输入学号、姓名或账号片段推断。`school_client` / `personal_school_client` 与原mock分开，正式项目 `school_official` provider仍为not_configured。学校客户端成功不声称取得正式应用SSO接入许可。

## 取数与会话契约

| 查询 | 范围及实际行为 |
| --- | --- |
| 本人资料 | 官方菜单的 `yhxx_cxYhxx.html`，按公开脚本确认为空表单POST；只取必要本人字段 |
| 课程成绩 | 来源 `xn/xq`；当前支持秋冬/春夏，不用单季冒充半学期成绩 |
| 主修成绩 | Celechron主修接口的全部历史，显式`ALL-HISTORY`，禁用学年/学期筛选，保留各行原年份 |
| 课表 | 来源 `xnm/xqm/xqmmc` 与可见列表模式 `xxqf/xsfs`；缺时间/周次/中选状态保持未知 |
| 考试 | 来源 `xxq/xnxq`；秋、冬、春、夏逐季查询，期中/期末原值分别保留 |
| 培养方案 | 使用学校本人资料的入学年、学院、专业匹配实际SELECT选项，再定向读目录和观察到的PDF资源 |

401/403、登录跳转、200登录HTML及JSON踢出都不会当成业务成功；异常只返回稳定代码，不返回学校正文或带票据URL。SSO仍有效时允许一次不带密码的教务会话更新，新的来源代次必须复核本人。来源失效409保留本机身份供同主体重登录；本机身份过期401要求重新进入。

学校真实响应适配补齐了三处协议差异：CAS的execution接受有界的长参数；认证菜单只继承学校实际返回的角色和页面上下文，URL中的会话标识与缓存时间不保存或输出；部分JqGrid响应同时包含有效currentPage和未使用的整数pageNo=0，只有明确正currentPage存在时才去除该零值，真实页码冲突仍拒绝。登录诊断只记录固定步骤、HTTP状态及timeout/tls/network分类，不记录响应正文、账号、Cookie或票据URL。

通用客户端串行、有界分页，默认最多3页和一次临时重试；超预算保留部分覆盖。学校网络请求默认8秒，允许的配置上限30秒。退出立即撤销本机会话并关闭学校客户端，不等待阻塞请求；迟到响应不能恢复Cookie、身份或发布旧用户数据。重登录期间退出、过期或被另一连接替换时，未安装的新客户端及时关闭。

成绩来源学分不等于已获学分，页面已选不等于正式中选，PDF取得不等于毕业规则核验；不同修读实例继续分开。无可靠校历不生成真实日期或ICS。

## 培养方案和缓存

培养方案不再依赖仅有2026级的预缓存全集。按已认证本人资料定向获取当前适用候选；不能由学号推入学年，也不套2026方案。候选缺少项目/路径/类专业或出现多个匹配时保留待确认，不建立verified适用绑定。

目录的专业下拉初始为空，须按官方联动流程先使用本人入学年、学院对应的源选项请求专业列表，再选唯一精确名称匹配。仅采用该专业代码查询当前本人目录，不枚举其他年级、学院或专业。目录中的方案编号必须来自该次查询，客户端不接受任意PDF地址。

首次按需取得唯一候选PDF后，校验类型、字节头/结尾、大小和SHA-256，存成本人私有不可变版本；后续可取已有版本或明确刷新。取得状态为`acquired_pending_review`，规则为`not_reviewed`，绑定为`not_verified`。这轮没有把PDF自动变成可执行推荐规则。

本人查询短期缓存默认5分钟，只在同授权/主体/连接代次内使用，并标注历史缓存和读取时间。页面“读取最新数据”强制查询；授权失效、主体变化或来源结构异常不会伪装实时。方案私有版本不进入原2026参考库、R3共享资料、DeepSeek或Embedding。课程目录的学期更新任务本轮没有运行。
