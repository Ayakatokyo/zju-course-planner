# 培养方案本地持久向量库

本机管理员可对已获准培养PDF批量入库及检索。主应用现已通过Qdrant服务端复用已授权候选片段的向量；本人授权、每轮学校取证、引用和版本校验保留。数据库仅监听回环地址，不向登录用户开放全库。年级决定增量写入策略，不能授予资料访问权限。

## 存储与处理

初始批次使用Qdrant本地持久模式（`QdrantClient(path=...)`）；当前已迁移到本机独立Qdrant服务端，旧本地库保留回退，不依赖Docker或云端服务。依据[官方客户端说明](https://github.com/qdrant/qdrant-client)，本地模式适合开发与原型；生产多进程部署应迁移到Qdrant服务端，不能让多个进程同时打开同一个本地目录。

- 原PDF继续位于采集批次，不复制到数据库；来源清单包含2023—2025本轮文件及2026历史复用。
- 沿用`personal_evidence`的坐标提取、选择性本地OCR、去水印和结构分块。正常文字页不强制光栅化。页码、原始文本、坐标、OCR状态及待复核质量存入`catalogue.sqlite3`。
- 本地固定版本BGE-small-zh-v1.5，512维、CLS池化及L2归一化。大段按480 token切分、40 token重叠，禁止静默截断。模型及运行依赖按原清单校验。
- Qdrant存储向量及来源元数据；SQLite额外保存文本内容对应的向量缓存，跨文件相同文本无需重新编码。PDF哈希、提取/分块/清洗版本及模型清单哈希共同区分版本。
- 文档全部向量写入成功后才标为ready并切换有效文档。中断后可续跑；部分文档不参与查询。旧版本证据保留，不冒充当前学校来源。
- 检索要求明确年级及方案编号，在该文档范围内做向量与汉字双字词法RRF融合，返回原文、页码、PDF哈希和质量标记。相似度不替代培养认定。

## 本机运行

可选依赖隔离在`private/vector_runtime/venv`，不改变基础服务及原语义运行环境：

```sh
uv venv --python private/semantic_runtime/venv/bin/python private/vector_runtime/venv
uv pip install --python private/vector_runtime/venv/bin/python \
  qdrant-client==1.15.1 onnxruntime==1.23.1 tokenizers==0.22.1 numpy==2.5.4
```

已有环境无需重建。固定模型及中文/英文OCR语言文件沿用本机已验证配置，不从网络下载文档或调用远程Embedding。

```sh
COURSE_OCR_TESSDATA="$PWD/private/ocr_runtime/tessdata" \
private/vector_runtime/venv/bin/python -m course_assistant.curriculum_vector_store ingest \
  --root private/curriculum_vectors \
  --encoder-manifest private/semantic_runtime/manifest.json \
  --manifest local-only/curriculum_2023_2026_20261025/manifest.json
```

重复执行可恢复并复用。若报告中出现`ocr_resource_limit`，可使用相同参数将`ingest`改为`retry-ocr`，逐页限时补做此前因交互预算未处理的页面；原提取结果保留备份，重建相关文档的派生向量并清理过期片段。识别无文本不自动认定为空白，需要查看原页。导入结束后才能从其他进程打开该本地库：

```sh
private/vector_runtime/venv/bin/python -m course_assistant.curriculum_vector_store audit \
  --root private/curriculum_vectors --encoder-manifest private/semantic_runtime/manifest.json

private/vector_runtime/venv/bin/python -m course_assistant.curriculum_vector_store search \
  --root private/curriculum_vectors --encoder-manifest private/semantic_runtime/manifest.json \
  --cohort 2025 --plan-number 20250921 --query '专业必修课程有哪些要求？'
```

上述CLI查询是本机资料检索，不会自动调用DeepSeek。主应用的RAG仍由现有Agent选择工具、授权证据服务准备候选并交给模型；登录后台准备只做取证/提取/向量复用或获准增量，不调用生成模型。

数据库、OCR文本、向量、日志与真实查询结果只放Git忽略的private目录。备份应在关闭库后复制整个`private/curriculum_vectors`，并保留源PDF及采集manifest；不得只复制Qdrant目录而遗漏文档状态和来源。实际完成数量与质量统计见`last_ingest.json`和开发进度，不以“入库完成”表示全文语义已验收。


## 当前批次验收结果

2026-10-25完成604份、176,915个512维向量；538页本地OCR、6479页原生提取。两页仅水印空白已经渲染核对，OCR资源限额遗漏已补齐。整批重开重复导入零新增编码，8项限定范围真实检索检查通过；不是完整问答或政策语义验收。实际数据与本地检查约2.5GiB。

本集合超过客户端建议的本地20,000点规模，当前单进程功能已验证，但本地模式不提供生产级多进程并发保证。现已迁移至下节所述Qdrant服务端，并接上既有本人权限与文档版本绑定；尚未进行公网并发验收。


## Qdrant服务端与主应用（第129节）

本机服务为Qdrant 1.15.1官方Apple ARM二进制，HTTP监听`127.0.0.1:6333`，关闭遥测及集群；存储在`private/qdrant_server/storage`。二进制来源与下载SHA-256记录仅本机保存。文档集合启用磁盘向量、磁盘HNSW及payload，文档ID、PDF哈希、年级和方案编号建payload索引。原176,915点已完整迁移并完成HNSW索引，原库未删除。

除原文片段集合外，`curriculum_embeddings_<model_identity>`保存去重文本向量，迁移43,089条，不保存学校凭据、姓名、学号或文本正文。主应用按已获准的候选文本哈希读取向量，继续原RRF、课程号优先、来源页码和本人引用；不会因为数据库包含其他专业就扩大检索权限。CLI整库管理员检索可加`--qdrant-url http://127.0.0.1:6333`直接使用服务端KNN。

### 登录异步策略

- 成功认证后进入有界后台队列（最多2个执行、总容量4），立即返回登录响应；验证码/登录失败不排队。
- 仅使用服务端可信档案中的年级。2023、2024、2025、2026级只检查和复用，**登录时零新编码、零增量写入**；缺项返回`existing_corpus_missing_vectors`，不按“库里应该有”冒充完整。
- 其他已知年级先检查本人PDF哈希及提取/分块版本，复用已有页文本；再检查模型版本/文本哈希，缺少的部分才进行本地Embedding并写入。同一文档再次登录不重复OCR或编码；未知年级不自动写入。
- 新年级的页文本缓存在`runtime_extractions.sqlite3`，按服务端本人realm/owner、PDF哈希、提取与分块版本隔离；只提供精确缓存查询，不参与跨用户RAG。源PDF仍需当前本人授权和字节核验。
- 本人PDF来源、页文本及引用仍保存在既有隔离证据仓库；后台任务在读取、写向量前及结束时核验会话。队列满、失败及撤权如实记录，不阻塞登录，不回显异常详情。
- `GET /api/auth/session`返回当前会话的`curriculum_preparation`状态。精简前端未增加新设置或准备面板。
- 已覆盖年级的交互检索若遇旧/新分块格式不同，可临时编码缺失片段以保持原检索行为，**不写入数据库**；此时`encoded_count`非零不代表增量入库。已核对样本各有1—3个此类长片段。
- 本轮没有为登录取证改掉既有每轮学校核验策略，也没有扩大成绩、课程班次采集。

### 启动与迁移

固定本机模型、OCR语言文件、Qdrant二进制及配置已在private中。启动脚本检查服务健康，必要时启动本机Qdrant，然后启用主应用的持久库及异步准备：

```sh
python3 scripts/run_vector_app.py --enable-school --port 18875
```

如需保留模拟账号，附加原来的`--scenario-bundle`、`--scenario-accounts`、`--scenario-pdfs`参数；历史课程条件测试仍需原有环境变量，启动脚本不会擅自扩展课程范围。当前在线启动保留了既有模拟账号与获准历史课程配置。应用重启会清空内存学校登录，需要重新登录，不能转存凭据避免此步骤。

单独迁移旧库（确定性ID可重复执行，不重新OCR/Embedding）：

```sh
private/vector_runtime/venv/bin/python scripts/migrate_curriculum_qdrant.py   --root private/curriculum_vectors --url http://127.0.0.1:6333
```

原始SQLite目录不能直接当作服务端存储目录。备份服务端应使用Qdrant快照或停止服务后复制整个server存储，并保留PDF、采集清单、模型清单及证据数据库。本机启动脚本不安装开机自动运行服务。公网部署、TLS/访问凭据和跨主机网络策略仍另行实施；此轮不对外开放6333/6334。
