## 4. 验收证据与保留契约

用户先前已亲测两账号登录和取数；本对话实际本人正常查询核验了地点、成绩学年/学期投影、考试关联、字段省略、左侧时间以及最终卡片布局。观察时不输出本人原值，只保留固定结构计数或几何指标；公开截图仅含合成数据或匿名登录页。学校原始标签页自动读取连续超时，因此学校菜单DOM逐值对照未完成，不把它当作已有证据。

最终工作区在本轮归档重新执行**790/790完整工程回归**，无skip/fail/error，见[归档测试日志](../validation/school_ingestion_closeout_20261015_tests.txt)及[最终源码验收](../validation/school_ingestion_closeout_20261015_acceptance.json)。第46/47/48/49节743、749、786、790项为各自历史记录；第50节91项是当轮课表/Web回归，不能混写成同一次测试。拆分后的第一提交树另跑786项，用于验证过渡版本，不冒称完全还原历史源码。

最终课表实际页面计数见[布局验收](../validation/school_timetable_blocks_20261014_acceptance.json)：11个占用单元格、12个课程卡片出现、9个考试块、2个未定位课程、10行时刻，最大垂直居中偏差小于0.14px。卡片与考试次数是当前查询的展示出现次数，不能当独立课程/考试数量。合成页面验证重叠/多时段、长考试卡、13节及夜间时刻、未知时段保留和安全转义。最终增量未重跑窄屏页面，下一轮整体改版应实际验证桌面和窄屏。

数据获取收口后继续遵循这些契约：

- 分页覆盖取决于实际预算，不把60/104条称完整历史；筛选/展示翻页不会自动取下一页。
- `sfqd`和未核验数字码不等于正式中选；成绩、额定学分不直接等于已获学分。未知字段可不展示，但内部不改成已知或零。
- 学校静态课表页尚未取得可靠动态作息，当前公开校历参考仅用于显示；限定2025–2026/2026–2027 AW/SS和明确本部地点，特殊校区反证拒绝引用。已知非法时刻不替换，合法metadata缺节不混补。这是保留的来源适配事项，不重开整个登录/取数设计；它也不提供用于ICS或冲突计算的日期/周次校历。
- 培养PDF获取成功与本人适用绑定、规则审核分开；真实推荐前解决必要依赖，不能以取数通过代替业务认定。
- 正式学校应用SSO和整体业务/权限验收独立；不得以790项工程测试替代。

## 6. 后续：真实本人Agent推荐接入

现有`chat.py`、`model_client.py`、`recommendation.py`、`recommendation_dialogue.py`、`recommendation_storage.py`已支持DeepSeek和R0—R2合成闭环；持久对话历史、比较、锁定调整、保存/导出及独立R3本机参考也有前轮实现。**不是从零实现一个聊天框。** 实际学校身份目前仍在`server.py`被`real_recommendation_not_ready`保护，bootstrap和chat/status明确不可用；本对话没有删除这道保护。

在前端改版后设计并实现获准真实输入→受限工具→确定性推荐的最小闭环：

1. 核对现有学校字段怎样成为本人可计算的学业、培养适用、候选课程/班次和时段输入，记录缺失与版本；不要把页面显示课表自动当候选目录或正式锁定课表。课程目录更新仍需单独明确范围，当前没有由此授权全校采集。
2. 复用已有对话与工具协议，把真实owner/realm、来源和输入版本贯穿读取、历史、工具、缓存、保存与导出；输入学号、名称或模型参数不授予访问权。
3. 需求提取、澄清、偏好继承和工具执行分开；计算工具给出具体推荐，模型解释依据。保留锁定/固定、无解、unknown及搜索上限，模型/RAG不替代规则审核与计算。
4. 明确实际模型及必要传输字段。学校取数授权和本次“下一阶段实现”的方向不自动授权将整份真实档案/成绩/原文发给远程模型；先形成具体可审核的数据使用方案，再按授权范围执行。
5. 按真实需求到真实工具结果、多轮调整、数据版本变化、超时/未配置、越权、会话失效和保存导出逐项验收；实际选课仍由学生在学校系统完成。

阅读[Agent对话与模型接入设计](Agent对话与模型接入设计_v1.md)、[推荐能力线设计](推荐能力线产品与技术设计_v1_20261013.md)、[R3及推荐交接](开发交接摘要_20261014_推荐闭环_界面精简_R3本机参考.md)和当前代码。旧设计中的未接模型、无历史等历史状态以实际实现为准。
