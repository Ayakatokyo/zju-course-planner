# 推荐能力线执行方案与新对话交接 v1

日期：2026-10-13。状态：待审阅执行方案，阶段均未按本方案实施。产品流程、具体合成课表示例与技术契约见[产品与技术设计](推荐能力线产品与技术设计_v1_20261013.md)。

执行目标是交付“Agent对话取得多个具体课表，并支持连续调整”的首个完整synthetic体验，再将获准本机真实依据与秋冬观察接成条件性参考推荐。RAG S1—S3嵌入这一主线；Embedding、真实文本生成及学校本人接入按各自条件另行推进。

## 1 审阅与新对话安排

本轮只设计。设计交付后按用户要求新建本项目执行对话，使用 `gpt-6.1-sol`、`ultra`；新对话先只读承接方案，等待用户审阅后明确开始。该配置用于Codex执行对话，应用运行模型仍沿用现有DeepSeek适配，不由此更换产品模型。

[规划入口第8节](开发交接摘要_20261013_推荐能力线规划入口.md)要求“先形成可审阅的方案……等待我审阅后再进入实现”。因此新对话准备与派发不表示实现开工；只有用户批准的阶段进入开发。用户批准合成闭环后可连续完成R0—R2，不在每个可逆改动前重复询问。真实假设场景用途、安装/下载Embedding、真实材料模型出站与学校接入保留单独授权和依赖。

首个可交付里程碑是R0—R2：真实模型驱动的完整合成推荐、两个实际差异方案、连续修改及保存导出。R3是下一个里程碑：真实资料与具体观察班次的本机受限参考链路。两者分别验收，R3不成为R1/R2前置；R4为可选增强，不能拖延已可实现的推荐主线。

执行中可独立并行准备真实首片候选/证据目录和合成算法，但运行接入、契约修改和最终验收由一个交付负责人整合。不存在未审核规则自动启用、模型下载或恢复采集的隐含步骤。

## 3 代码改动范围与实现注意事项

| 入口 | 复用与拟改 | 关键限制 |
| --- | --- | --- |
| `planner.py` | 保留固定请求课程的生成及完整校验；增加可解释分量或由推荐层计算；复用比较 | 不把整个候选池填入`requested_course_ids`；新课程子集要以对应约束完整复核 |
| `audit.py`、`server.enrich_plan` | 复用分账与预计贡献，抽出明确的预测计算接口 | 现审核只接受synthetic/demo_active/DEMO版本；真实参考另用独立项目审核契约，不伪装DEMO，不将假设通过写学业账本 |
| 新推荐编排层 | 有限课程子集＋班次搜索、统一全局预算、排序与多样性、完整范围状态 | 单个子集有解/无解不等于整个课程池搜索结论；截断、unknown、未覆盖规则分别记录 |
| `chat.py` | 工具接候选/推荐/比较和显式操作patch；服务端校验语义/权限/版本；结果解释结构化 | 相容旧工具保留；更换/放宽/解锁不能只信模型声明；资料注入不授予变更意图 |
| `storage.py` | 持久意图/预览/结果引用、动作幂等、预期轮次/修订；新增工作区/方案/会话/回执共同提交的事务方法 | 从服务端状态解析A/B和旧结果；不能顺序调用各自提交的方法冒充原子保存；文本压缩不能删除锁定、固定项或版本 |
| `server.py` | 从服务端预览引用取结果，应用条件/保存事务及只读导出桥接 | 现`frozen_result`要求当前工作区版本和条件；不改客户端版本绕过。保存后同步会话基线及结果状态 |
| `web/app.js/index.html/styles.css` | 默认对话内条件摘要、具体课表、方案差异和明确操作；复用现有展示 | 程序结果与模型解释分清；显示版本/unknown/保存状态。失效方案不能继续点击保存为当前已校验 |
| `reference_retrieval.py`及拟议参考工具 | 保留旧54块行为；按RAG v2另建真实受限目录/精细块/解析器 | 不直接换源挂mock；动态查询全量分页绑定版本；引用走授权解析器，不公开私人路径 |
| `model_client.py` | 复用协议、限额、凭据隔离和错误处理 | 不自动改供应商/产品模型；新合成夹具须明确固定出站范围，不能开放任意导入数据 |
| `scripts/course_source_adapters.py`及离线成果 | 只读利用持久manifest/证据别名；适配受限观察投影 | 了解现状不重跑写派生目录的脚本；新派生产物独立版本，不动原件和个人状态 |

首片支持的计算规则限定为经定义的模块学分/门数目标、必选/排除、课程/班次锁、个人学分范围和现有时间/资格三态。路径择一、认定或互认等复杂要求若未被该切片支持，标未覆盖并阻止相关完整结论，不以“目标模块通过”代替毕业通过。

搜索采用一份全局预算，不能每个课程子集重新得到完整节点额度。小池用独立穷举结果验证搜索；较大池允许预算内结果，但须显示候选裁剪及截断。首片先保留标准库/SQLite/原生Web，不新增求解器或向量数据库；性能若成为真实阻碍，再用实际证据决定扩展。

增加兼容的共享预算/叶候选输出接口，让推荐层在现生成器按周五排序及`[:limit]`截取之前接收已复核叶候选；预校验、课程子集和班次节点共用预算，候选池及诊断有界。搜索截断与结果保留裁剪分别记状态，不能从每子集的前三份输出推断完整推荐排名。测试覆盖旧接口兼容、有价值候选未被旧周五排序提前丢弃，以及资源预算。

跨课程方案比较需推荐层逐套构造“共同必选＋该套可选”的低层校验条件；不能让所有备选课程一起变成必须满足的`requested_course_ids`。R1增加这一对照，R2保存后检查会话基线已同步，后续追问仍使用保存的意图、锁与输入版本。

## 4 最小数据工作包

### 合成工作包

另存推荐夹具，保留原演示及inputs。包括：一个合成目标模块、明确获分/在修/未知的账本、至少三个可选课程和同课多班、体育锁定/预置/固定安排、完整合成校历/考试、纯合成内容说明及引用。主示例见产品设计第4节；再增加同课换班、周次分离、只有一解、锁定冲突、unknown、容量/版本变化等独立变体。

期望由独立的人工可复算规则和工程对照定义；助手准备的fixture及预期标为工程测试数据，不称人工gold。模型替身覆盖协议与失败路径，实际模型调用和页面操作单独取得证据。

### 真实首片局部核对

| 数据 | 只核对首片所需内容 | 未核对时的结果 |
| --- | --- | --- |
| 方案与路径 | 标题/年级/专业/路径、目标模块、问题页隔离 | 参考范围待定，不建立本人方案绑定 |
| 要求与课程关系 | 数值/单位/且或/任选、完整表头/跨页/星号附注、普通课程集合 | 关系待审核，不能自动计算有效贡献 |

| 具体班次 | 目标学期、快照内源键、完整观察束及全部多时段 | 候选班身份或时段unknown；不跨观察拼接 |
| 周次与校历 | 原891条附注中与首片有关内容及解析依据、节次/日期映射 | 保留原文与unknown，不借合成校历补真实 |
| 资格与考试 | 完整先修/对象规则及考试日期/时区 | 相关校验unknown，不默认无限制/无考试 |

| 权限与用途 | 本机来源grant、共享字段白名单、新假设场景用途、结果/引用隔离 | 未获准不加载该域；当前远程chat不接受真实上下文 |

具体课程代码、私有定位、真实文本与逐行证据只放本机忽略目录；仓库设计和验证摘要只记别名、状态和去敏统计。首片选择形成固定范围记录；不足时报告缺口，不能为了两套结果补造开课。

自动工程验收要求这12项适用主用例全部通过，安全/锁定/候选误启用/伪事实断言零失败；适用用例的未执行不能记为通过。R0—R2只报告synthetic分母；R3按真实参考适用项另报范围和unknown，不混算真实本人验收。

实际模型验收另固定至少五条推荐会话：初次多方案及比较；soft→hard；明确换课/个人修改；一解/锁冲突；unknown/缺数据。每条至少两轮，包含对应实际工具与正确意图和最终结果；失败保留回执，不能挑成功轮声称整条通过。调用沿用用户已授权的synthetic服务范围，扩展夹具及问题须明确仍为纯合成；此轮设计不调用。

页面验收实际打开本轮运行版本，完成需求、比较、锁定/修改、保存和下载，检查桌面及390px窄屏。记录截图、点击路径和下载摘要；不沿用旧页面证据。用户选择自行验收时交付确切版本、访问入口与步骤，等待用户结果，不以自动检查代替其验收。

原八项整体与A01—A10的未覆盖部分继续未完成。新增结果只填对应范围；学校认证、真实本人源、完整规则及真实业务必须各取证据。

## 6 检索与引用验收

R3建议从现50题蓝图选取/补充本方案20题作为独立首片：代码/课程连接4题，条款/表头/跨页附注4题，无依据/适用范围4题，暂缓范围/普通课程保留4题，引用/冲突/撤销4题。问题及同义变体按意图成组，先冻结开发12、保留8，后人工核对原页、必要支持片段、禁用结论及允许引用；同意图不跨组。现50题95候选仍为machine seed，人工gold仍0。

只有实际完成人审的题进入检索分母。须分别报告可回答题召回、必需证据集合覆盖、引用定位/逐结论支持、无依据错误肯定、权限/scope/撤销结果；结构化清单完整性按来源及分页对账，不能用Recall@k证明全量班次。

首片继续门槛是：所纳入块的源/页定位全部回查；已审阅支持题均取得完整支持证据；无依据题零错误肯定，权限/scope/伪引用/候选误启用零失败。题目少时报告原始分子分母与失败清单，不声称总体准确率。若标注不足，不先套RAG v2的50题90%/95%门槛宣称通过；如扩到其原5方案范围，再按该版门槛和分母另验。

词法/Embedding/混合必须同块、同题、同过滤与候选预算；保留组不调参。比较支持证据和推荐场景的错误原因，不能将新增课程说明带来的提升记成Embedding提升。真实原文生成未获准时只做本机命中/引用审核，不编模型回答验收。
