# 开发交接摘要：学生来源重试取得小样本

2026-10-14。用户在首次入口失败后明确要求重试，并保留此前代为官方登录授权。本轮通过原生Chrome界面完成官方统一身份认证，已看到登录后的本人教务菜单；用户选择一个秋冬目标学期，另明确确认考试页的个人纪律承诺后才继续查看。凭据仅输入官方页，没有写项目文件、回执或本地验证程序，没有导出Cookie/Token/会话。浏览器登录成功仍不是本项目正式学校认证。

成绩/考试入口曾自动显示全部范围的第一页，未翻页或保存这些默认历史行。成绩经真实学年/秋冬筛选收窄后采集；考试初始显示条件与旧学年行不一致，切换实际秋/冬选项后重新核对目标结果。保留这一来源缺陷，不将初始旧行冒充当期数据。业务来源加载控制为资料1、成绩2、课表3、考试3、方案3个有限步骤；菜单选择和人工等待另列，不是自动网络抓取。
