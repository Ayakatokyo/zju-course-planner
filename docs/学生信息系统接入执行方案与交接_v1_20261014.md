# 学生信息系统接入执行方案与交接 v1

日期：2026-10-14。执行范围：开发最小只读来源适配、尝试用户本人官方会话下的数据取得、本地规范化与方案匹配；正式认证依据实际配置决定能否推进。详细架构及信任边界见[设计方案](学生信息系统接入设计_v1_20261014.md)。

用户本轮已要求设计后新开 `gpt-6.1-sol / ultra` 对话具体执行，允许尝试失败。新对话可以直接从I0开始，不把此前推荐规划的“待审阅”作为本次阻点。需要用户完成官方登录是实际输入依赖，不能自行处理密码；真实资料模型出站、应用申请、提交推送和部署不属于该指令。

## 3 真实探针预算和停点

首批探针限定本人资料、一个成绩查询范围、一个目标学期课表及可用考试页；不穷举路由/学生ID/年级。初步每域最多3个分页/加载步骤、业务查询串行，单次最多30秒、临时传输故障同请求最多重试1次。该预算是本试验默认，不是学校规则；正常人工登录等待不计入超时，也不自动重试凭据。

若3页仍未读全，标partial并交付当前分母；已有菜单明确有更多页且扩展确为本人的该域，可以在相同用途下分下一小批继续，不突然全量所有学年。响应明确登录失效、账号切换、验证码或访问限制时立刻停该域；用户在官方页面完成后才重启任务代次。连续出现同一接口故障不无限重放，保留明确失败。

仅在实际工具与页面允许时使用同源只读查询；源码中的POST query也需要确认其查询语义。上游成绩的showCount=5000不能作为完整性证据，课表季值及学年编码不能凭显示名猜。缺源主体字段时不发任意学号查询，按允许的当前本人页面记录缺口。

处理真实业务数据属于本次本机接入试验；不可因已登录推定学校为本项目批准服务端认证或公开/外传用途。源主体无法确认时不发布可信本人上下文；独立本机材料由授权操作任务持有，学校身份绑定保持未配置。

## 4 验收用例

以下用例按实际覆盖执行，每个保存输入/预期/源码摘要和结果；未执行写未执行。合成数据测试可验证工程行为，不能替代学校实测或用户字段核对。

| 用例 | 要验证的行为 |
| --- | --- |
| S01 登录页与数据页 | HTTP200登录HTML、跳转、401/403、空响应与合法数据区分；不能报成功空账本 |
| S02 当前来源身份 | 实际官方origin/页面来源、同会话关联；字段不足保持unknown，手填学号无权限 |
| S03 切换/退出 | 任务中账号切换或退出停止采集/发布；不能混合两账号来源，旧引用失效 |
| S04 用途与隔离 | 本机个人grant、mock、R3共享参考、正式provider分域；错误域/其他任务/撤销拒绝 |
| S05 凭据隔离 | 登录正文/隐字段/请求头不保存；字段白名单剥离后摘要明确；错误/日志不带票据或真实个人值 |
| S06 档案缺失 | 专业/入学年/路径逐字段状态；不按学号推断，不把姓名或截图变认证 |
| S07 学业账本 | 成绩原值/学期/额定学分/状态、修读实例候选、体育重复/替换/认定分开；未知不算获分 |
| S08 课表和考试 | 多时段、课表原教学班段、单双周/分学期原值、考试独立；缺身份/校历不合并或补全 |
| S09 覆盖与解析 | 分页/总数/范围和失败行对账；大量showCount不代表全量，错误行不静默跳过 |
| S10 幂等及发布 | 同来源版本重放不重复；新解析版本另存、不同范围不混；事务失败不改活动指针 |
| S11 方案匹配 | 入学年/项目/路径匹配；近名/多个候选澄清；找不到正确版本不套2026，手选不是可信绑定 |
| S12 过期/部分失败 | 本轮失败和旧缓存各自状态/时间；无来源不变零数据，旧版不当本轮实时成功 |
| S13 正式provider | 未配置正常拒绝；合成测试核来源/受众/时效/关联/重放/映射，只有真实验证另验后称正式认证 |
| S14 模型与产品回归 | 真实资料不送现DeepSeek/Embedding、不装mock；原推荐/保存/历史/R3验收范围保留 |
| S15 实际小样本 | 用户当前官方会话至少一个真实可读域（或实际失败）；字段/行数/学期/缺口逐项对照；没有该证据不称真实来源成功 |

交付状态至少分为：实现的适配器、工程通过项、实际取得的数据域、实际受限/失败域、用户核对项、方案候选状态、正式认证状态和推荐输入就绪度。没有账号/网络/接口也能完成I1并报告I2阻点；不能以“15用例”或历史385项数量替代真实接入。

## 5 用户参与和完成标准

需要用户参与时，执行对话只请求在官方页面登录或完成验证码，并指明浏览器/业务页；不用聊天接收学号、密码、Cookie，不要求上传Excel/截图。已有明确本人会话和本轮授权时，不为每次菜单/分页重复请求许可。

资料或范围选择有歧义时，询问目标学期、当前要用哪个本人会话或专业/路径来源；用户回答仅用于范围选择，不能增加身份效力。需要正式应用配置时列出缺少字段，不索取秘密配置到聊天、不替用户申请或联系学校。

首轮理想完成为：至少一个真实本人来源域取得且可复核，规范化、方案候选/缺口与本机私有报告完成；更完整的多个域成功按实报告。若尝试失败，完成标准是适配与异常验证、明确真实失败回执及继续条件，不强行让正式认证或真实推荐“成功”。

本任务默认不commit/push、不打包/部署、不安装Embedding或新模型、不改学校在线配置。每轮更新开发进度，最终写新交接摘要；公开只保留去敏证据，真实产物留忽略域。
