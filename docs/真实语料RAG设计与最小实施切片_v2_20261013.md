## 2. 第一版能够回答什么

首版是明确方案版本上的培养依据查询，加上当前秋冬样例的结构化观察查询。课程池总体共享；板块是查询出现关系，方案要求和本人状态另存。2026 方案与采集账号可见秋冬开课不是“2026 学生全员可选矩阵”。用户排除的跨类、搜索引擎、研究生入口及未采春夏不作为本轮前置。

| 问题类型 | 读取路径 | 允许结论与边界 |
| --- | --- | --- |
| 指定方案的模块、课程列示、外语层级或附注 | 带方案范围的培养依据检索 | 解释该版本原文，不自动把条文转成执行规则 |
| 准确课程代码、教师、时间、地点、考试或样例班次清单 | 受限结构化工具与分页 | 返回本批次观察，不依靠向量 top-k 列出全部班；不承诺实时余量或实际可选 |
| 方案列的课是否有秋冬开课观察 | 方案代码依据＋已核验代码映射＋批次查询 | 有观察、未在本范围查到或映射未确认；不说学校不存在这门课 |
| 课程兴趣、内容、难度、考核方式 | 已取得且许可适用的课程说明 | 名称、学分、教师不足以推断课程内容与难度；缺大纲返回缺依据 |
| 本人缺分、资格、冲突或毕业可行性 | 可信本人事实＋经审核规则＋确定性程序 | 真实个人源、适用绑定与规则未齐时 unknown；RAG 不给正式审核结论 |
| 多轮课表调整、锁定、比较与导出 | 原有确定性工具 | 继承锁定、预置、正式成员、固定项与输入版本；依据检索不改变这些条件 |

Agent 对话继续是入口。服务端先澄清用途和范围，再路由依据、结构化事实或计算。答案必须区分“培养方案列示”“本批次开课观察”“本人适用”“计算结果”，不能把四者写成同一种事实。

## 3. 共享池、要求关系与本轮业务暂缓

逻辑对象不要求一对象一表。建议在现有来源契约上增加以下投影；全部携带源版本、字段断言及状态。

| 对象 | 去重与 RAG 的关系 |
| --- | --- |
| `CourseDefinition` 与定义断言 | 学校＋代码体系＋经核验课程身份；同码矛盾定义保留。相似名、教师名和向量相似度不能建立身份 |
| `ClassificationMembership` | 课程在板块/筛选/账号观察上下文出现的关系；同课跨板块不复制成多份课程文本提高检索权重 |
| 候选 `Section` 及观察束 | 班次键只在已验证边界内归组；跨刷新稳定性未确认继续候选。学期、不同班及多时段分别保留 |
| `Meeting` / `ExamArrangement` / `CapacityObservation` | 上课、考试、动态容量分别查询；同一动态事实取一条真实观察束，不把不同时间字段拼成新快照 |
| `EnrollmentObservation` | 个人页面状态独立的受限域；共享课程投影、词法文本与向量中均不包含其字段或由其推导的标签 |
| `CurriculumPlanVersion` / `RequirementNode` | 方案、年级、路径、单位、比较符、例外、父子关系分别保存；不同方案的相同文字不合并为一条全校要求 |
| `PlanCourseMembership` | 要求节点与课程的多对多关系；必修、模块归属、建议学期、星号和适用路径作用于该关系，不能设成课程全局属性 |

用户明确暂不考虑第二、第三、第四课堂。本轮对这些要求、活动行、记点/认定和依赖条款设置 `business_scope=deferred_second_third_fourth_classroom`、`scope_policy_version` 和用户授权的暂缓理由。原文、物理页、账户、单位、条件与来源完整保留；这是项目业务范围，不是学校撤销要求。

本轮完整盘点的目录中，二、三、四课堂各有 162 个字段槽位：151 个 known，原值分别为 4/2/2 学分，11 个 not_provided；没有显式零，缺字段不能填 0。PDF 主标题各覆盖 151 份方案；这些是本批次文字/字段观察覆盖，不证明其余 11 份没有要求，也不证明所有本人适用。条文中的记点与学分继续分开保存。

普通课程推荐、学分计算及普通课程依据检索在评分前排除这些暂缓节点。专门的本机审核用途可以查看原文与盘点，且须显式与普通问答分开。问题直接要求计算二三四课堂时返回 `deferred_by_business_scope`，说明本轮暂缓和官方原要求保留，不用普通课程答案替代。毕业总要求保留原始 `minimum_credits_raw`（包括 `N+8` 等写法）；不得减去暂缓账户、改成新官方毕业线或承诺本人毕业。引用毕业原总要求时附项目范围说明，不推导支持范围内的新合计。

混合表格必须按行/条款标注：一个暂缓活动行不删除同页普通课程。跨页附注如作用于两种范围，保留依赖关系；普通课程块仅携带所需条件摘要，不能把暂缓详情通过 overlap 或表格父块泄回普通结果。章节边界不清的混合块先 `scope_status=pending`，不整块有效纳入。含“劳动”“实践”“体育”“实习”“毕业设计”的正常课程不得按关键词排除。

其他类似认定、独立账户、能力/合格要求只继承本轮盘点建议：`scope_status=review_proposed`，不自动视作 deferred。美育、劳育、创新创业、心理健康等若可由普通课程满足，保留课程修读和认定覆盖两层；同一获分事实覆盖多条件不重复增加实际学分。外语层级、合格要求、辅修/微辅修路径不等价于额外普通排课课程，具体适用范围必须澄清。完整类别、覆盖数量和原文证据以本轮盘点产物为准。

盘点特别登记了一个认定标题为显式 0 学分/0 学时、正文仍保留通用阈值的国际学生路径例子。0 是已知来源陈述，不能被“非空完整正文”覆盖成通用阈值；应同时保留例外标题与正文，待适用审核后才能给有效解释。医学综合课程/毕业考试、本科后转段、研究生阶段标准和毕业能力目标分别挂阶段/路径，不把“能够通过执业考试”文字当成本科已满足的硬性通过记录。普通体育、实验、劳动课程及学时均不因这些相似要求而排除。

## 4. 来源登记、适用性与冲突

全部 162 份先登记；首个精细切片选 5 份有不同版式或适用路径的文档，使用本机别名 EVAL-A 至 EVAL-E。候选包含工科模块、复合学位、国际学生路径、医学长表及衔接培养路径；登记成功不算已检索覆盖，最终是否纳入须按下述审核门槛确定。

`SourceDocument` 至少区分目录键、PDF 请求键、原件哈希、页文本哈希、实际观察时间、登记时间、提取器版本、目录元数据断言、标题断言、页级版本断言、来源用途与许可。文件摘要不是校方版本号；上传时间不是生效时间。计划键与 PDF 查询参数按实证关联，不只凭文件名。后续新增资料由登记接口提交完整批次，不能把“再次采集较晚”当成官方政策修订证明。

适用字段：学校、方案版本、年级、专业、主修/双学位/辅修/微辅修、方向、国际学生等路径、语言层级及有效期。`all`、`not_applicable`、`unknown`、`conflicting` 分开。用户指定方案只授权其允许的参考浏览，不能创建本人方案绑定；本人正式依据从服务端 `StudentPlanBinding` 和来源 grant 导出。缺年级、路径或绑定时 `needs_scope`；不靠检索相似度猜最接近的方案。

本轮全文扫描登记 4 份方案的页级年级冲突：目录/前文为 2026，导图文字为 2025；证据编号 `REQ-COHORT-f3b1f2d76cca`、`REQ-COHORT-d33e7bc820b7`、`REQ-COHORT-08b8745c8a77`、`REQ-COHORT-3a4617b15b04`。其中一份已列入 EVAL-D 代表切片。完整文本、方案键和页号保存在本机盘点问题文件，不写入公共定位清单。

登记保留两条断言和页定位，标 `page_applicability=conflicting`、`semantic_review=pending`，只隔离问题页，不丢弃整份文档。问题图页默认不进入有效 2026 依据；可在获准诊断用途展示冲突。不能因哈希正确、文件同属一份 PDF 或目录是 2026，就抹去图页差异；本轮局部视觉核对不等于全部问题页的官方适用/政策审核完成。

同范围内冲突必须关联 `conflict_group_id` 和全部断言。不同表用途的必选/选修差异先保留 `table_kind`，不直接改一方。动态容量按时点差异处理；身份/语义矛盾仍留冲突，不通过“最新值胜出”解决。`unknown` 不覆盖已知，但已知部分也不能暗示整条已验证。

## 5. 分块和精确引用契约

加工保留三个独立层：原页文与原件；可回查的清理/结构文本；项目建模解释。清理可去重复水印、处理换行等，但保留逐字符/片段到原页的映射和清理版本；不能把整理后的表格当成原始 PDF 内容。字符定位以明确编码和零起点半开区间 `[start,end)` 记录。原始页号采用物理页 1 起，不把印刷页号或目录页码冒充 PDF 页。

| 内容 | 块及关联方式 | 必须核验 |
| --- | --- | --- |
| 章节/要求条款 | 一条完整条件为原子块，标题链和单位随块保存 | 否定、上下限、任选/且/或、适用前提不能被截断 |
| 课程表 | 表对象＋表头块＋课程行块，行含课程代码/名称/学分/性质/原列 | 表头缺失、跨列黏连和空白不能自行补值；指导性计划不等于主培养表 |
| 跨页长表 | 以表身份连接两页，分别保存每个片段 locator | 续表表头来源、相邻页逻辑连接需人工确认，不只凭相似版式合并 |
| 附注/星号 | 独立注块＋作用对象边，获取行时带必要附注 | 星号适用辅修还是主修、例外作用哪些行；未知作用域使结论待确认 |
| 账户与合格要求 | 原文块＋指标/账户断言，分别标业务范围 | 学分/门数/学时/记点/合格条件不混用，不自动父子求和 |
| 导图/图示/OCR | 保留页源，`extraction_status=layout_or_ocr_unverified` | 未核验图形读序或年级冲突时只作诊断，不作有效答案证据 |

为检索使用短原子块，展示时按需扩展同授权的父章节或相邻条款；父块与重叠只提供语境，不能让同一要求被多次评分/计数。块大小先按完整语义决定；超过所选模型预算时再切成带相同父条件的子片段，记录截断，不能默默丢尾部。不要按“每页一块”或固定字符窗口直接拆所有表格。

最小元数据契约：`chunk_id`、`logical_content_id`、`source_version_id`、`source_sha256`、`page_text_sha256`、`text_sha256`、`schema/parser/mapping/cleanup/chunking` 版本、`document_role`、`review_status`、`business_scope`、`scope_policy_version`、适用字段与状态、`data_scope/security_realm/owner_student_id`、许可/用途版本、冲突/unknown 依赖、物理页片段和可用 locator 精度。`chunk_id` 来自源版本＋定位＋处理版本＋文本摘要；同文本不同方案可复用本地编码缓存，但须保留各方案独立逻辑块和要求关系。

引用由服务端签发不透明证据引用，不接受模型自造源路径、页码或块 ID。回查时检查 live 授权、适用性、scope、源/块/语料版本与摘要，再返回受许可原页或片段；不得泄露本机绝对路径、Cookie、学校 URL 中的会话参数。逐条结论绑定支持片段：主课程表结论不能引用只含相同课名的导图；跨页结论引用全部必要页段，明确其依赖附注。引用定位存在、文本支持结论、对本人适用是三项分别验收。

## 6. 取回前权限与工具契约

本轮资料仅在获准本机 `restricted_reference` 用途登记，不因课程池共享就转为匿名公开。现有 mock 仍只绑定独立 synthetic，不能以 A/B 身份读取真实课程观察中的个人状态。首个真实资料切片是独立本机参考审阅入口，不改 `/api/import` 为真实接入，不把 `ReferenceIndex` 换源后直接挂在 mock 对话上。

顺序固定：校验会话或本机审阅授权 → 可信主体/绑定 → 来源 grant 与用途 → 允许语料版本 → 安全域/本人范围 → 方案与路径、页级适用、业务范围与审核过滤 → 只对候选集合评分 → 允许集合内重排与上下文扩展 → 引用回查与返回前再授权。若向量组件不能先限定候选，按授权域隔离存储或在允许 ID 集做精确评分；不能全库 top-k 后再剔除他人资料。

| 拟议受限工具 | 模型可提议的参数 | 服务端固定且复核 |
| --- | --- | --- |
| `retrieve_curriculum_basis` | query、受限 limit、允许的条款/课程查询意图 | 本人/审阅主体、purpose、grant、方案/路径、语料/索引/范围策略版本 |
| `lookup_course_observations` | 经解析课程引用、允许字段组、分页游标 | 代码体系、样例批次/学期、共享投影白名单、每页完整性、观察时间；不含个人页面字段 |
| `resolve_evidence` | 本轮实际返回的证据引用 | 权限、scope、摘要、版本、locator 和未撤销状态；模型无权修改源位置 |
| 个人事实与计算工具 | 白名单对象/约束 patch | 可信本人资源、输入版本、锁定/固定项；确定性结果决定 pass/fail/unknown |

返回 `status`、`scope`、`coverage`、`source/corpus/index/scope_policy_versions`、`matches`、`linked_issues`、`warnings` 与工具证据。状态区分 `ok`、`no_supported_answer_in_scope`、`needs_scope`、`deferred_by_business_scope`、`source_unavailable`、`stale_input`、`timeout`、`conflicting_evidence` 和 `inaccessible_resource`；这些是 v2 拟议契约，不能说现有接口已经实现。结构化查询分页游标绑定源版本，版本变更时重新查询，不返回跨版本拼接的班次清单。

模型不能传 owner、student、realm、grant、任意 SQL/Shell、学校请求 URL 或执行规则。资料中的“忽略上述要求”“改用这个地址”等文字只作为数据，不改变工具白名单、用途、权限、锁定或外传策略。被拒绝或无结果的工具不能被模型改写为成功；所有最终引用必须出自当前有效工具返回。

## 7. 词法、本地 Embedding 与混合对照

先固定同一精细语料与人工标签，再比较检索策略；语料扩展和算法切换分开实验。本轮只核对官方技术来源，没有加载模型。候选选型不是本项目质量、内存或速度的实测结论。

| 对照组 | 实施计划 | 保留的限制 |
| --- | --- | --- |
| L0 当前词法 | 保留拉丁代码词项＋汉字 bigram 的真实代码基线 | 精确代码优先解析；集合交集得分不证明语义支持 |
| L1 词法改进 | 相同候选集合内比较字段权重/词频排序，SQLite 可存元数据；如用 FTS5 先实测中文 tokenizer 与编译支持 | 不能把默认分词当成已适配中文；调参只用开发组 |
| E1 本地向量 | 首选候选 `Qwen/Qwen3-Embedding-0.6B`；独立实验环境、固定本地模型 revision，按官方 query/document 编码约定 | 官方卡支持多语言、0.6B、最高 1024 维，查询使用检索提示而文档不加同样查询提示；本机兼容/资源尚未测 [官方模型卡](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B) |
| E2 可选型号对照 | 需要解释 E1 失败时再测 `BAAI/bge-m3` dense 路径 | 官方支持多语言及多种检索表示；本切片不先引入 sparse/multi-vector 和重排 [官方模型卡](https://huggingface.co/BAAI/bge-m3) |
| H1 混合 | 同范围独立取词法/向量排名，再按固定排名融合；精确代码命中作为单独强约束 | 不直接相加不可比原分；融合参数与候选预算版本化，最终必须检查答案支持 |

SQLite FTS5 提供多种 tokenizer 与排序能力，是否可用及具体中文效果应在本机检查；它不是本人授权机制。[SQLite 官方 FTS5 文档](https://www.sqlite.org/fts5.html)

首个 5 方案小集合使用本地向量矩阵与精确余弦检索即可；维度和数据量实测后再决定存储，暂不要求独立向量数据库/ANN。检索之前限定许可集合，元数据与正文分别保存。跨板块同课只建立一个已确认共享课程文本投影；不同方案要求保持独立。可按 `text_sha256+embedding_config_digest` 复用相同文本的本地向量，但复用向量不合并要求、权限、来源或答案适用性。

向量配置固定实际模型 revision/权重摘要、tokenizer、pooling、查询指令、维度、归一化、精度/量化、依赖与设备路径、最大长度/截断策略、文本构造和清理版本。查询与文档配置兼容才可评分；换维度/模型不混用旧向量。模型许可与学校材料许可分开。本轮授权只交付设计，不自动下载模型、训练或向量化真实文本；外部 Embedding 不在切片范围。

相似分数只是排序信号，向量总能返回近邻不代表材料有答案。无依据判定应综合范围、缺失依赖、召回覆盖、明确支持片段及已标注的无依据组，不预先编通用相似度阈值。否定、多条件、先修和正式资格仍由澄清/受限工具处理。

## 8. 版本更新、撤销与缓存

源版本、精细语料版本、索引版本、向量配置版本及业务范围策略版本分别记录。批次候选清单包含全部输入摘要和构建契约；新索引写独立版本，执行完整性/引用/权限检查后原子切换。失败保持旧版和失败原因，不能半更新。删除/撤销/替代是独立事件：来源变更未证明替代关系时保留并列版本；正式 supersedes 必须有证据，不按取得时间自动推定。

业务暂缓属于 scope policy 变更，过滤立即按新策略生效；旧索引虽保留原文，也不能继续返回已暂缓普通结果。恢复业务范围可重用保留材料，但必须重新核验适用、来源许可与依赖，不能把恢复范围算成官方政策更新。

首片不启用个人缓存或语义答案缓存。纯参考检索缓存以后至少包含 realm、purpose、允许 corpus/grant 的版本集合、方案/路径范围、scope policy、index/chunking/embedding 版本、规范化查询、精确字段/过滤和候选预算；有本人信息还须 owner、身份/方案绑定和输入/授权策略版本。凭据不作为缓存键，不把私人查询写共享日志。

命中仍 live 授权并核对依赖；退出、到期、撤销、用途缩减、绑定冲突、源换版或范围策略改变时拒绝旧缓存。无命中缓存也随语料版本失效。TTL 只管性能，不能使未知时效变成 current。异步任务在入队、运行、提交和取回时重新校验固定主体及 grant；权限撤销后阻止提交/下载，清理派生文本与向量按来源留存政策处理。原件不可改写要求与未来撤销处理冲突时，先停止访问并保存事件，不擅自删除本轮证据。

历史方案、历史引用保留当时源/规则/范围策略，查看时注明历史状态且重新授权；重校验使用新输入产生新结果，不修改旧方案。对话或缓存中的往轮 citation 不能成为当前结论，必须重取并验证。个人流式输出发生退出/撤销时停止后续片段，不在流式尾部继续返回旧授权内容。

## 9. 50 题评估蓝图与人工标注

本机交付别名 RAG-EVAL-V2 包含 5 方案登记、50 题、95 处候选原文定位、元数据完整性回执与构建脚本；所有候选片段的页/字符区间/摘要回查一致，无缺失的种子锚点。每题的 `annotation_status=machine_seed_unreviewed`；`gold_evidence=[]`，没有人工金标或模型答案。自动提取的片段仅证明存在于页文本，不证明片段完整、适用或答案正确。蓝图中设计的预期行为和拟议分组不算已跑测试；构建脚本只重建 machine seed 文件，未来人工金标另存，避免复跑覆盖人工审阅。

| 题组 | 题数 | 主要检查 |
| --- | --- | --- |
| 精确课程代码/同名 | 5 | 代码精确定位、代码体系、跨方案近名不混 |
| 模块/账户/单位 | 5 | 保留官方总原值，门数/学时/学分分开 |
| 适用范围与路径 | 5 | 本人绑定未知、外语层级、国际学生/学位路径 |
| 表格/跨页/附注 | 5 | 引用全部必要页段、表用途与星号作用域 |
| 认定/多条件覆盖 | 5 | 普通修读与认定分开，不重复增加实际学分 |
| 开课/动态观察工具 | 5 | 完整分页、时点一致、候选身份、多时段/unknown |
| 二三四课堂暂缓 | 5 | 普通检索排除、总要求不减、正常劳动课程保留 |
| 无依据与能力界限 | 5 | 不从名字推课程难度、规则缺失不猜、不说全校不存在 |
| 权限与来源注入 | 5 | 他人资源/伪身份/撤销/恶意文本/出站限制 |
| 更新/冲突/引用 | 5 | 页级年级冲突、旧引用、unknown、失效缓存、模型伪引用 |

同一意图组及其自然语言改写只能落同一分组；蓝图拟定 30 题开发、20 题保留，须在人工标注前冻结。保留组不用于调阈值、分块和融合参数。最少两轮审阅：先逐题核对 PDF/页文/表头附注与方案适用，记录支持/部分支持/无依据/拒绝、允许引用及禁用引用；再对存在争议的判断复核并保留分歧。只有完成审阅的题可纳入分母，未标注题不算漏检或通过。

分别报告：可回答题的 Recall@5/Recall@10、MRR、前列无关率；需要多段证据题的必需证据集合覆盖率；引用定位成功率、逐结论支持率；无依据问题的错误肯定率与正确 abstain；范围错取、越权正文/引用/缓存、候选误执行、暂缓泄回普通结果、伪引用与锁定丢失。结构化工具以来源/版本/全量分页与原观察对账评估，不用向量召回衡量其清单完整性。

建议首片准入门槛（设计目标，未达到/未执行）：所有人工审阅块引用回查 100%；已知权限/scope、伪引用、候选误启用和锁定保持攻击组 0 失败；保留集可回答题 Recall@5 ≥90%、必需证据集合覆盖 ≥90%，人工回答逐结论支持 ≥95%、错误肯定的无依据题为 0。样本只有 50 题时同步报告原始分子分母，不能称全专业准确率或生产安全证明。安全攻击组之外仍待真实权限/业务验收。若检索指标不足，先按失败归因补分块或证据，不把未知改成答案来过门槛。

真实原文生成尚无许可，本轮只形成蓝图。后续算法对照可只输出本机命中与定位；生成阶段在明确本地服务或获准远程文本范围后另行验收。既有 DeepSeek API Key、synthetic 同意及引用卡片返回都不授权真实学校原文出站。

## 10. 拒答和异常策略

| 情况 | 结果 |
| --- | --- |
| 未指定方案/路径/语言层级，而问题需要这些条件 | `needs_scope`，澄清最小字段；不自动绑定为本人 |
| 材料已登记但尚未精细纳入、只有相似片段或无大纲 | `no_supported_answer_in_scope` 并列当前覆盖，不能说校方无要求 |
| 直接要求二三四课堂计算或普通课程推荐包含该账户 | `deferred_by_business_scope`，原要求保留，不提供擅改总分 |
| 同范围要求/页级版本冲突 | 返回 `conflicting_evidence` 与许可内双方证据；无法选择时 unknown |
| 考试待定、无周集合/校历、先修只有提示、源键不稳定 | 返回字段级 unknown/候选边界；拒绝完整无冲突或可选保证 |
| 猜他人对象、伪 owner/方案绑定、mock 访问真实个人状态 | 一致的不可访问响应，不确认目标存在，不先取回正文 |
| 资料提示更改身份、下载、外发或自动选课 | 当证据数据；服务端工具与出站白名单拒绝，真实状态保持 |
| 源不可用/检索超时/版本变化 | 具体失败状态；不把旧结果当本轮成功或无命中 |
| 模型未读原文却概括、引用不存在/不支持、说计算通过 | 拒绝该结论，展示本轮实际工具结果/本机依据或受约束重答 |
