## 2. 始终有效的产品与数据边界

目标链路：学校身份登录 → 服务端可信本人绑定 → 获准取得本人档案与学业 → 对话表达需求并澄清条件 → 受限检索 / 确定性工具 → 课表推荐、比较和依据 → 保留锁定条件的多轮调整与重校验 → 本人保存 / 导出。实际选课仍由学生在官方系统完成，本项目不自动执行。

- 学生身份来自服务端验证的认证结果与可信绑定。姓名、学号、对象 ID、模型输出或客户端 `owner` 不授予访问权。所有本人数据、来源文件、未来对话、检索缓存与导出都应在取回前按本人范围授权。
- 学校认证协议、应用注册许可、可信学生属性 / 映射尚未确认；项目不存或自行验证学校密码。官方登录成功与取得档案 / 成绩 / 选课 API 是独立问题。
- 固定 A/B mock 默认关闭，只连接独立 synthetic 数据，不验证现实使用者身份；不能用 mock 接真实记录，也不能在官方认证失败后自动降级。
- Excel 与两张真实截图只作字段 / 结构 / 状态参考，不规定真实用户必须上传。私有原件和定位在 `private/` 或外部路径，不进 Git；截图临时路径可能失效，需要时重新取得可复核样本。
- 原 `inputs/zju_course_agent_handoff_v1/` 不改写、不裁剪；原 23 条候选继续待审核，真实教学班模板仍为空。审核产物、解析结果、新版规则另存；检索命中不能使候选自动生效。
- 缺班号、周次、状态、规则、校历或认定依据保留 unknown，不用演示值补齐真实记录。课程 / 教学班 / 上课时段 / 考试分别处理；修读实例 / 课程身份 / 认定归属分别处理；备选志愿 / 页面已选 / 正式中选 / 已获学分分别处理。
- 偏好更新继承锁定、预置、正式来源成员、固定项及输入版本，再调用确定性程序。模型和 RAG 不能替代授权、官方规则审核或计算；不能为了生成课表静默放宽硬条件。

## 5. 下一对话建议：先设计接入契约，再设计检索

以下是供新对话讨论、核对的工作顺序，不表示本轮已经完成或可直接启动真实采集。

1. **核对本人来源与许可。** 分别列出认证、可信绑定、档案 / 个人要求、成绩 / 修读 / 认定、当前选课 / 正式结果、当期开课、校历 / 节次 / 考试和公共规则来源。记录已经可用、仅有字段样本、待校方许可与尚未知的项目；不预设学校 OpenAPI 或通过输入学号查询全库。
2. **定义原始层、映射与版本。** 为每种来源确认获取方式、允许访问者、更新 / 覆盖范围、解析版本、原始观察与规范化记录、稳定标识、字段三态、幂等和来源冲突处理。个人要求不覆盖通用方案；个人替换不能升级为全校互认；未知不补造。真实和 synthetic 使用明确分开的来源 / 存储域。
3. **设计权限链与最小接入切片。** 公共培养依据可与个人材料分别推进；个人源必须先有可信本人身份和来源许可。选择一种确有可复核样本的来源定义映射与验收，再扩大范围；若只具备字段参考，可以先完成规范与合成解析夹具，标为设计 / mock。
4. **设计 RAG 数据集合与检索契约。** 按培养方案 / 年级 / 专业 / 路径 / 有效版本 / 目标学期 / 审核状态 / 本人 owner 与 realm 过滤。公共依据与个人数据分域，取回前授权；缓存包含本人、授权和输入版本。设计 chunk 元数据、出处（页 / 段 / 单元格 / 原始观察）、覆盖范围、陈旧 / 缺失 / 冲突策略及引用返回。不要先把所有资料放进一个索引再让模型筛选权限。
5. **确定检索与计算的分工。** 结构化个人事实优先通过受限数据工具查询；RAG 用于依据和解释，不直接生成有效执行规则或修改学业账本。先定义可复核问题与基准，必要时从标准库 / SQLite / 关键词检索开始，不预先强制向量库或新框架。
6. **确认模型接入与对话工具闭环。** 模型推理可来自远程 API 或本地服务，尚未选型 / 配置。对话架构与工具映射已有设计，尚无 `/api/chat`、模型适配器、工具包装或对话持久化。可先独立 synthetic 验证需求提取、澄清、计算工具及连续调整，再接检索。API Key 只在服务端；真实个人材料外传需明确服务与范围，不因学校数据获取许可自动获准。
7. **分别验收。** 数据：归属 / 幂等 / 状态 / 覆盖 / 冲突 / 版本；RAG：适用性 / 引用 / 漏检 / 过期 / 越权 / 恶意来源文字；Agent：语义误解 / 结构错误 / 幻觉 / 超时 / 撤销 / 版本竞争 / 锁定继承 / 真实工具结果。拒绝或 unknown 是正常路径，不伪装成功。

原八项业务与 A01–A10 权限整体仍未完成。A01 官方认证、A05 检索 / 模型 / 缓存 / 任务、A08 维护角色尚未实现 / 执行；现有 synthetic 会话、对象和 HTTP 验证不能扩展到这些未来对象或生产环境。具体逐项边界见 [验收范围](../validation/验收范围_20261009.md)。
