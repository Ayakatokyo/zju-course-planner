`student_sources.py`不发网络请求、不接模型或主应用。grant在取回/发布前重验，新代次使旧正文引用失效并把旧状态标历史。来源别名不成为可信身份；业务标识仅以私有摘要检查连续性，同页或跨域混入不同主体即停任务，无标识仍为unknown。

保存内容是字段白名单投影，摘要不冒充完整HTTP字节。登录正文、隐藏认证字段、请求头、HAR、Cookie/Token/密码不保存；业务值中常见凭据赋值和头部字符串也拒绝。不同范围/刷新或映射变更须新任务代次，现未提供旧版批量重解析发布接口。

程序强制3页预算和SQLite事务串行发布。30秒/次和临时重试1次是浏览器策略，**没有自动网络传输适配器**；`automatic_network=false`，不能把离线导入测试称为网络单飞/超时/重试验收。

成绩保留`xkkh/kcmc/xf/cj/jd`、额定与来源报告获分，实际`earned_credits`仍unknown；同码体育、认定、替换独立。课表保留全部时段与`sfqd/dsz/xxq`原值，考试独立，缺校历不推真实日期或生成ICS。档案缺值、相近专业名不会生成可信适用结论。

## 本机入口与继续条件

CLI仅接受本项目`local-only/`或`private/`内路径。以下均为占位符：

```sh
python3 scripts/run_student_source_probe.py --root <私有任务目录> --grant <私有grant.json> init
python3 scripts/run_student_source_probe.py --root <私有任务目录> --grant <私有grant.json> start --term <已选择学期> --origin <已核对官方origin>
python3 scripts/run_student_source_probe.py --root <私有任务目录> --grant <私有grant.json> ingest --attempt <任务ID> --input <已剥离业务观察.json>
python3 scripts/run_student_source_probe.py --root <私有任务目录> --grant <私有grant.json> readiness --attempt <任务ID>
python3 scripts/run_student_source_probe.py --root <私有任务目录> --grant <私有grant.json> --output <新私有报告.html> report --attempt <任务ID>
```

还支持describe/failure/revoke；`init --synthetic`不能接真实资料。envelope按代码白名单校验，不接受密码、Cookie、Token、请求头或任意路由。stdout仅去敏状态/计数，正文只在私有报告；报告转义、无远程资产、独占创建且不覆盖旧文件。

继续先恢复可读官方页面、正常登录/验证码并选一个目标学期，再建立新代次沿本人菜单小批取得业务字段。当前无法判断账号/密码或校方拒绝，不用旧缓存/mock替代。正式provider另需获准应用、协议验证、项目回调、受众、可信映射及个人来源许可。

本轮未commit/push、部署、打包、下载模型/Embedding、外传真资料、申请学校权限或操作选退课。原inputs、23候选、A/B、R3共享grant和主应用工作区保持原范围；原八项及学校权限整体未完成。
