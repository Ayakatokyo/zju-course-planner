# 教务数据展示设计

状态：两入口与数据展示已实施（2026-10-25），已进行本人实页核对；用户验收待完成。范围为桌面端数据组织、字段与交互，不改变对话主入口，不执行选退课。依据[字段分析](教务数据来源与截图对应_20261025.md)，不把历史样本当作实时结果。

## 1. 导航与页面职责

保留「对话」「本轮方案」，将原「成绩记录／我的课表／考试安排／资料与培养」合并为「学业情况」「课程安排」。页面内用连续区块、筛选和行内展开，不按接口新增页签。

| 入口 | 回答的问题 | 来源 |
| --- | --- | --- |
| 学业情况 | 已完成哪些培养要求，哪些课程有成绩，哪些状态还需核对？ | 毕业自审、成绩、主修数据、本人资料、培养PDF |
| 课程安排 | 所选学期何时上课、考试，哪些已选课程还没有时间？ | 课表、考试、当前选课预览 |

## 2. 学业情况

页面从上到下：本人背景 → 培养进度 → 课程记录。背景只占一行；培养进度与课程记录是主内容。读取按钮按业务标注，不暴露接口名。

入学年份 · 学院 · 专业或类（专业）    本人资料 ▾  培养方案PDF
读取时间与本次范围；如部分来源失败，在对应区块提示

培养进度
总要求：学校原值；学校自审结果：原值
模块          已获 / 要求学分    完成 / 要求门数    自审结果
▸ 模块甲           …                  …              …

### 培养进度字段

| 字段 | 来源与规则 |
| --- | --- |
| 模块名称、层级 | JDMC、JDDM/FJDDM，按树显示；同名模块不能按名称合并 |
| 已获／要求学分 | YXXF/YQXF，保留复合值；不将父子模块加总，不将159+8改成167 |
| 完成／要求门数 | YXMS/YQMS；仅在字段有意义且有值时展示，不把缺值改成0 |
| 自审结果 | SFTG；根标记等编码未经核验不替代明确文字状态 |
| 认定说明 | RDXKCXF、替代说明等放行内详情，标注学校原值；不自行再算可计入学分 |

总要求直接取对应根节点，不从模块求和。首版不做“毕业完成百分比”、综合GPA或推算欠缺学分。未通过模块可筛选，但不自动生成确定的必修欠课清单。

### 课程记录字段

| 主表字段 | 展示规则 |
| --- | --- |
| 课程 | 名称主行、代码次行。无代码时保留独立记录，不按名称合并 |
| 课程学分 | KCXF或成绩xf；明确对应且一致时显示一次，不一致显示“来源值不同”，展开并列 |
| 自审状态 | 通过／在修／被替代／不通过／未明确。无自审关联时为“未关联自审”，与空自审状态区别 |
| 成绩 | 只有一个可确认的成绩记录才显示具体值；多条显示“多条成绩”，展开逐条查看，不选最高值或自行取最新 |
| 归属模块 | 自审父节点路径；多个认定位置显示多个归属，不以课程去重消除认定关系 |

主表默认基于本次自审课程记录组织；用户补充学期成绩或主修来源后，可靠对应的记录挂到同一课程组，无法对应的保留在“未关联培养模块的记录”中。默认不请求所有历史学期。主修数据用「补充主修记录」按需加载，不把无成绩条目统计成已修。

课程行内详情保持两个事实区：

- 成绩明细：来源成绩、来源绩点、学年学期、修读/选课课号。缺少逐行学期时可显示“查询范围：某学期”，不能伪装成源字段。
- 自审认定：模块、选必修、学校状态、在修备注、替代说明。一个课程可有多个自审节点，全部保留。

在修不被缺成绩覆盖；有成绩不被提升为通过。自审中的成绩仅代表该认定节点的成绩，不能未经核对补成某次修读成绩。来源数字冲突并列呈现，不由前端选择“正确值”。

模块点击联动课程清单，清单顶部显示已选模块及「清除筛选」。搜索、模块与状态筛选只处理已读取数据。明细采用行内展开，避免为了看一门课再开页面或页签。

### 本人资料与培养PDF

默认只展示入学年份、学院、专业或类（专业），按原字段名称显示。姓名、学号、入学日期、培养路径等置于「本人资料」折叠区，缺项不造值。培养PDF使用现有本人授权下载/阅读能力；获取状态与适用核验状态分别保留，文件存在不代表适用已确认。

## 3. 课程安排

```text
课程安排    [学年] [秋冬／春夏] [分学期筛选]    更新课程安排
本次读取时间与覆盖范围

课表（页面主体）                本范围考试（同页侧栏）
星期 × 节次                    有日期的按日期排列
课程／教师／地点／周次          时间未提供的单列
点击课程 → 行内或固定详情区     点击考试 → 对应课程详情

未排定时间的课程
课程／教师／分学期／已知选课状态／缺少的安排

当前选课信息 ▾  [读取当前选课信息]
已选清单、志愿及当前专业课程教学班预览
```

课程安排按课表学期驱动；考试请求对应分学期，标注秋/冬或春/夏，不把两季同名课程自动折成同一次考试。首版展示本范围全部已获取考试；只有具有可靠完整日期、时区的事件才能用于“近期”排序，未解析时间保留原文。考试侧栏过长时在同页展开，不增加考试tab。

| 对象 | 默认字段 | 展开字段 |
| --- | --- | --- |
| 上课时段 | 名称、教师、地点、分学期、周次、星期/节次 | 课程代码、教学班/选课课号、原时间表达、已关联考试 |
| 考试事件 | 名称、期中/期末、日期或时间原文、地点、来源分学期 | 教学班关联、其他明确状态、来源与读取时间 |
| 未定位课程 | 名称、教师、已知分学期、缺项说明 | 可用原文及明确对应的选课状态 |
| 已选教学班 | 名称、教师、志愿、学校选上状态、上课时间地点 | 班次号、与课表关联结果 |
| 待查看教学班 | 名称、教师、时间地点、余量/容量 | 班次号、考试原文、学校明确选择状态 |

主课表负责上课事实，考试侧栏负责考试事实。选中课程时突出其关联考试，而不把全部考试文字重复堆进每个课表格。不能关联的考试仍在侧栏显示。缺时间用“时间未提供”，不能直接称“待发布”，除非学校明确返回该状态。

当前选课信息与所查历史学期分开：独立显示官方返回学年学期，不能把2026当前已选清单拼到2025课表。默认折叠、手动读取；维持已实现本类（专业）前10条范围，不声称全校目录。只预览，没有真实提交按钮。

## 4. 数据整理层：聚合显示，保留事实粒度

采用轻量派生视图，不改写来源原件，不新建另一套权威成绩或毕业账本。模型不参与字段关联和状态计算。

| 对象 | 身份与关系 | 不可混合的内容 |
| --- | --- | --- |
| 来源记录 | 本人范围、来源、快照/批次、行或节点标识 | 读取时间、学校更新时间、查询学期 |
| 课程显示组 | 同一来源可确认的课程码/节点；跨来源需明确且无冲突的标识 | 课程显示组不等于唯一修读实例 |
| 修读成绩 | 源实例号，或明确选课课号与范围；不够唯一则逐行保留 | 重修、多成绩、自审成绩 |
| 培养认定节点 | 批次内JDDM；FJDDM组成树，引用课程组 | 同一课程的多个模块认定 |
| 教学班与时段 | 具体班次标识、选课课号、学期；班次下保留多时段 | 目录父级xkkh不等于具体教学班xkkh |
| 考试事件 | 明确考试ID或完整事件观测、类型、来源范围 | 同一班次的期中/期末、多场考试 |

匹配顺序：先校验本人及来源范围 → 明确实例/班次标识 → 无冲突且可信的课程身份 → 未解决保留独立。相同代码最多支持课程分组，不能独自证明两条成绩属于同次修读。名称仅用于搜索，不用于身份合并；新旧课号不自动映射。即使名称和分数恰好一致，也不据此删除记录。

同一来源同一不可变记录的重复传输可消重；跨来源重复先关联到显示组，明细仍保留出处。空值不覆盖其他来源值，冲突不隐藏。课程名等显示字段有多个不同值时使用当前主来源名称并提示其他来源名称，不伪造统一名称。

## 5. 获取、刷新与失败

- 首次进入页面展示来源尚未读取与对应按钮，不把空缓存变成0，不启动全历史预热。已有同会话数据可显示，始终带其真实读取时间。
- 「更新培养进度」查询自审；成绩按选择的学期补充，主修按需补充；PDF继续使用现有按需流程。加载自审失败不阻止已有成绩查看。
- 「更新课程安排」读取所选课表与相关分学期考试；每个来源独立显示成功、失败和读取时间，不能用一个“最新”覆盖混合批次。部分失败允许查看成功部分。
- 切换来源或学期只更新对应区块，不能覆盖其他来源已获取事实。重新查询失败，旧值只能明确标为上次读取；身份、权限或会话失效时清空本人派生视图并要求重新验证，不展示旧人数据。
- 同页面重复视图使用相同来源记录；不因展开行、筛选或排序重新请求学校。跨轮对话仍执行既有按轮取证，不以页面缓存替代。
- 来源信息使用简短来源名、读取时间和必要范围；原始代码及字段诊断不占主表，不新增对话依据/过程入口。

## 6. 实施顺序与验收

先实现纯数据投影与关联函数，保留原接口和原始记录；再迁移两个导航入口与同页展示，最后验证普通旅程。初期无法可靠关联的记录允许独立呈现，不以追求单行完整度制造错误映射。

| 场景 | 可观察结果 |
| --- | --- |
| 自审含模块、课程和重复代码 | 模块树完整；课程分组不丢认定节点/成绩，父子学分不加总 |
| 成绩无独立课程码，仅有选课课号 | 仅在已有可靠关系时关联；否则单列，不按名称猜 |
| 同码多成绩或两源不同成绩 | 详情逐条显示；不擅取最高/最新，不冒充GPA |
| 模块通过但仍有空状态备选课 | 模块保持通过，课程状态未明确，不批量标欠课 |
| 只有课表课程、没有时间 | 保留在未定位列表，不从已选状态生成时段 |
| 同一课程有期中、期末考试 | 两场保留，未知时间不显示为无考试 |
| 当前选课期与所查课表期不同 | 明示不同范围，不跨期合并 |
| 一源失败或身份切换 | 成功来源单独可用且有时间；身份失效清空全部本人派生状态 |
| 导航与操作 | 只保留两个教务入口；模块筛选、课程展开、考试关联均在同页完成 |

本稿不代表接口覆盖、正式毕业认定、真实选退课或用户体验已验收。实施后需实际桌面页面核验，工程测试不能替代上述旅程。


## 7. 实施记录

- 页面展示层按来源和查询范围保存会话内快照；课程代码与一致名称支持显示分组，选课课号仅在唯一且无冲突时补充关联。原始成绩与认定节点保留。
- 培养模块按父子关系缩进显示，长列表局部滚动；点击模块可筛选其后代课程。课程按名称/代码、自审状态、是否有成绩筛选，展开保留明细。
- 课表与分学期考试同页，课程与考试可双向点选。未知时间保留；同学期选课预览仅按唯一选课课号关联，当前范围不匹配时独立呈现。
- 成绩、主修、自审、课表和考试各自保留读取时间、范围和失败状态；身份失效清空派生视图。来源值不足时不强行合并，因此仍可能看到同名独立记录。
- 已核对本人自审、主修、课表、考试与选课预览；实时选退课仍未启用。本轮不改变对话取证逻辑，不减少后端接口，先将重复信息组织成两个页面。
