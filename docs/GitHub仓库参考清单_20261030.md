## 6. 统计口径与使用说明

- 明确引用的外部仓库：Agent/Harness 4 个、学校接入 1 个、前端设计 4 个、检索及组件 3 个，共 12 个。
- Qdrant 服务端、BGE 模型、ONNX Runtime、tokenizers、NumPy、OCR 工具、PyJWT 等在运行资料或代码中另有使用证据，但不因为依赖名称出现，就把其上游 GitHub 仓库写成“开发时参考过的仓库”。完整依赖及其上游映射需要另做依赖清单。
- ChatGPT 接入记录引用官方 Sign in with ChatGPT 文档，现有明确仓库引用中未出现 `openai/codex`，因此不擅自将其算作源码参考。
- 工具辅助研发、采用开源组件、参考设计和独立业务实现应分别表述；此清单不证明用户独立阅读、编写了所有相关实现，也不改变原有业务验收范围。

可用于项目介绍的表述：本项目在学校接入上参考 Celechron 的客户端协议实现，在 Agent 设计上参考 DeepSeek Harness、Pydantic AI 和 LangGraph 的职责与状态管理思路，在前端交互上参考 assistant-ui、Agent Chat UI、CopilotKit 和 shadcn/ui；实际使用 Qdrant 客户端和 pdf-lib，并通过 Harness² 独立开发工具进行候选对照。Qwen3-Embedding 属于早期选型候选。
