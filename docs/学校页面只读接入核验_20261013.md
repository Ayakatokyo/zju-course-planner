## 接入路线

1. **本机只读来源适配**：用户本人完成学校登录后，适配器在当前可见页面查询、展开、翻页、取得对应文档；记录实际观察时间、筛选、学期、页码、展开范围和加载结束标记。先做一个目标培养方案、一个学期局部课程的可复核样本。不得操作选课、退选或志愿提交。
2. **培养依据路径**：结果行→对应原文/PDF→文件摘要及原始观察→逐页核对→带年级/专业/版本/出处的RAG块。官方来源可得到本轮来源证据，但本人适用、现行修订与原有候选规则的执行审核仍需分别确认。
3. **教学班路径**：课程与括号代码、班行、时段、考试、余量、页面选课状态分别规范化，供受限工具计算。未知周集合/稳定班号/具体先修规则/校历保留unknown；“已选”和“已选上”保留原始语义，不能无条件升级为已核验正式结果或已获学分。
4. **真实运行接入**：浏览器登录态是本轮页面访问条件，不自动成为项目服务端的学校认证与可信本人绑定。正式提供本人查询仍须落实认证、来源授权和版本发布。不能把真实样本装入synthetic工作区；模型出站策略继续独立。

网页观察需新增明确的 `web_dom_observation` 类型及DOM/表行定位契约；现有字段字典只列原文档类型，不应假称已有通用学校网页解析器。保存不可变观察、规范化映射版本和差异；重采局部页面默认追加，不因没看到旧行而删除事实。

本轮验证了来源可达、DOM读取和一份PDF预览。分页/全分类遍历、PDF下载与全文解析、稳定班号、更新幂等、正式本人绑定均未验收。原inputs未修改，23候选仍待审核；没有业务代码变更，不重跑历史213项测试，未提交/推送/部署。
