# 浙江大学选课助手开发进度

最近更新：2026-10-09。当前代码版本 **0.2.0**；本文为统一进度入口，历史设计/交接中的暂停和未运行状态不代替本轮证据。

## 1. 当前状态与范围

用户已在新对话明确恢复开发。本轮按 S2 身份/本人授权/synthetic 隔离 → P0 学业与数据 → P1 方案比较、锁定、调整、重校验和导出的顺序整合，交付可运行的本机 synthetic 应用。服务仍使用 Python 标准库、SQLite 与原生 Web，无第三方运行依赖。

本次后续纠偏（顺序 10）已恢复 **Agent 对话默认入口**，原表单保留为“条件与课表”辅助入口。用户通过对话获取推荐课表是核心产品设计，模型/RAG 暂后置不意味着删去主交互。当前只是页面内需求草稿、示例、未配置提示和独立合成预览；发送禁用，草稿不发送、不解析、不参与计算。真正自然语言理解、多轮编排、模型工具调用及 RAG 仍未实现。

**已实现并验证本轮列出的合成切片；学校真实认证、本人学业来源与整体真实验收仍未完成。** 固定 A/B mock 仅用于独立演示，不验证现实使用者身份。学校认证未配置时拒绝，不存学校密码，不用自报学号授权，登录也不表示已取得档案 API。Excel/截图仅作字段参考，不要求用户上传。

原 inputs 未改写，17 项清单哈希及内嵌七份数据一致；原 23 候选继续待审核，真实教学班模板仍空。真实未知不得使用演示值填充。当前 source 账本没有本人数据，摘要显示待确认；空输入的已核验小计不作为本人真实总账。
