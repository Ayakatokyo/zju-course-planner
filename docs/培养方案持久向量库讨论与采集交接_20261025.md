# 培养方案持久向量库：讨论结论与采集交接

日期：2026-10-25。初始范围为总结讨论、先采集PDF。采集完成后用户追加授权：继续在当前对话完成OCR/RAG与持久向量入库；随后追加授权完成Qdrant服务端迁移、主应用接入和登录异步准备；公网部署尚未实施。向量库操作入口见[运行指南](培养方案向量库运行指南.md)，实际批量结果见开发进度第128节，应用接入及最终年级策略见第129节。

## 已明确的方向

- 批量取得2023、2024、2025、2026级全部专业的培养方案PDF，作为后续向量库的基础语料。覆盖指教务系统当时认证账号可见、明确年级及全部学院/专业筛选下的目录，不推断其他年级或不可见资料。
- 后续统一对该批文档提取文本（必要时OCR）、分块、Embedding并持久入库。不是只向量化文件名，也不是训练模型。
- 单个用户的培养方案仍从学校后端核验和获取；登录后即可触发本人文档的准备，已有一致版本则复用；最终规则为2023—2026级只查复用，其他可信年级才补入缺失部分，无需等待首个问题。
- 文档与索引可持久保存，访问授权仍按当前可信身份核验；登录失效不要求删除全部索引，但不能继续通过失效会话访问。
- 已有162份历史数据只证明2026级当时目录的下载完成，不等于2023—2026级已完成，不等于当前RAG已全部接入。

## 初始实施建议（历史讨论，当前实现以第129节为准）

1. 登录后异步准备本人文档，避免PDF下载/OCR/Embedding阻塞登录；以未准备、准备中、可用、失败记录真实状态，不用演示数据填补。
2. 将用户与文档的可信访问关系、原始文档版本、派生索引分开管理。专业/年级标签用于匹配和检索范围，不能单独授予访问权限，也不自动认定培养适用。
3. 原始PDF、页码、OCR原文及质量保留；文档内容哈希、提取/分块版本、Embedding模型版本共同决定索引是否可复用。字节变化先保留版本，不能直接认定政策发生修订（水印/生成元数据可能变化）。
4. Qdrant是当前建议候选，选型及部署待实施时确认；保留词法召回、页码引用与授权检查。结构化成绩/课表不因引入向量库而改为近似检索。
5. 同内容公共培养文档可考虑去重复用，但用户必须分别建立可信访问关系；含个人信息的文档按本人隔离。服务端生成检索过滤条件，不让模型指定用户身份。
6. 新版本入库成功后再切换有效指向；部分失败可恢复，旧版本不冒充最新。检索未命中与文档尚未入库分别处理。
7. 登录触发准备与每轮学校取证是不同策略。本轮没有修改现有每轮取证逻辑；后续单独确定更新检查频率、过期策略和失败提示。
8. 验收至少包括重启后向量复用、同版本不重复编码、更新后版本切换、跨用户隔离、失败恢复，以及与现有词法/混合检索的召回和延迟对照。

## 本轮采集范围和产物

用户本轮明确授权扩展至2023—2026级培养方案。仅做目录/PDF只读获取，不采集新范围的成绩、课程班次或其他学校端点，不实施选退课，不向模型或向量数据库发送本轮文件。

沿用此前已验证的浏览器登录态内后端请求路线与原采集器；原采集器及历史批次不覆盖。每个年级先核对页面筛选、后端总数与分页，再逐项根据实际目录对应的方案身份下载。单并发、有限重试；遇登录失效、验证码、403/429等停止并保留回执，不通过换会话绕过限制。

输出目录：`local-only/curriculum_2023_2026_20261025/`（Git忽略）。每个年级分别记录目录项数、唯一方案数、成功PDF数、失败数、未请求数、来源时间、文件哈希和父目录对应关系；文件按内容去重时保留所有目录映射。原始PDF及详细回执只留本机，不入Git。

历史2026级批次不得计入本轮新下载数；如后续选择复用，必须标为历史复用并记录校验依据。未取得实际目录前，不预设四个年级的总文件数。
