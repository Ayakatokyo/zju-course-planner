# R3 本机参考首片实施与验收

2026-10-14，用户要求先完成界面精简和Codex式历史侧栏，再实施R3。历史侧栏已在18865实际页面验证后推进本首片。R3工程链路已实现并取得限定的本机证据；人工检索与业务验收尚未完成。原R0—R2合成应用和原参考索引保留，真实首片没有挂接A/B远程对话。

## 实施范围

复用既有离线交付和来源盘点，不新增学校请求。162份培养方案登记为元数据目录，本轮获准正文只有别名EVAL-A的一份方案，按主修路径、一个模块、秋冬观察范围处理。已重新核验该PDF、页定位文本与所用8个共享组件哈希；其余161份只继承历史登记，未重新读取正文或作语义审核。真实原件、专业/课程标识、定位、索引签名密钥和报告均保留本机Git忽略目录。

助手渲染并逐页查看选定的5个物理页，核对标题、模块完整条款、跨页课程行和辅修附注，排除前后必修续表及实践/毕业等范围外行；将6个子组的目录数量与模块学分要求分开。源文列示模块要求8学分，与场景计划8学分、官方毕业总要求分别记录；第二、第三、第四课堂按既定业务边界暂缓，不按活动关键词删除普通课程，也不改原官方总要求。该核对标记为`assistant_reviewed_pending_human`，不作为人工金标或官方规则启用依据。

## 当前结果与验收

最终真实首片生成3套不同组合，每套4个观察班次、8计划学分；均为`conditional_reference`且`result=unknown`。计划学分按所选课程观察学分求和，不评定模块有效贡献或本人完成情况，不代表本人剩余学分、完成毕业要求或实际获分。每套11项待确认，当前所选时段没有观测到节次重叠，但周次、校历及完整考试等仍未知，不能称完全无冲突。资格、本人学业和适用、班次稳定身份、历史余量、关系人审等保持未知。

搜索访问2,000/2,000节点，组合保留上限64也发生截断；预检查完成与全局组合未穷尽分别报告。结果不称全局最优，未观察26代码不能解释为学校不开课。既有兴趣内容没有证据，不生成难度、好过、适合本人等推断。

## 后续验收边界

在私有20题工作表逐题核对原页、必要支持集合、路径适用与允许结论，完成同意图分组的人审后，才能计算检索召回/引用支持和拒答分母。保留8题不得用于调参。若有错误则在相同版本与范围中修正并复验，不以20项工程检查代替人审。

R4的Embedding、词法/向量对照及真实参考模型生成尚未实施。学校本人认证、学业/资格、可靠校历/周次与原整体验收未覆盖部分保持待确认；不进行选课或退选。原inputs和23条待审核候选未改，本轮未提交、推送、打包或部署。
