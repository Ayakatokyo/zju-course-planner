# Agent 任务续接与失败恢复

日期：2026-10-16（Asia/Shanghai）。接续[数据链路与对话体验交接](开发交接摘要_数据链路与对话体验.md)及开发进度第64—65节。本轮聚焦日常查询的任务完成与续问，不改变已验收的学校直接登录和教务界面。

## 1. 依据与参考

当前真实页面复现了明确学期概况之后的省略式续问失败：供应商理解了原学年和新季节，但提出的中文学期参数不符合工具的规范编码；执行前校验结束了整轮。该现象属于任务契约和错误恢复，不是学校读取已经失败，也不是前端隐藏了成功答案。真实问题、答复、推理和精确运行定位仅留本人私有域。

另两项源码问题可以独立复现：混合领域、各有年份的请求会交叉准备不相关范围；读取历史失败前先清掉当前会话和未发送草稿。对未取得根因的旧终态过程展开现象不宣称修复。

参考官方 DeepSeek Harness，固定只读版本 `86a402200d95fecef4529d969836f1fe13c6cb0d`：

- [会话事件及续接](https://github.com/deepseek-ai/deepseek-harness/blob/86a402200d95fecef4529d969836f1fe13c6cb0d/docs/subsystems/core.md)：将任务状态与会话事件分开；本项目只承接查询意图，事实每轮重读。
- [架构](https://github.com/deepseek-ai/deepseek-harness/blob/86a402200d95fecef4529d969836f1fe13c6cb0d/docs/architecture.md)：持久运行事件、实时增量和聊天展示分开，不把模型提议等同工具执行。
- [循环及失败契约](https://github.com/deepseek-ai/deepseek-harness/blob/86a402200d95fecef4529d969836f1fe13c6cb0d/packages/core/agent-loop/README.md)：借鉴执行前与执行后状态区分。其单步并发限制不是整轮预算，本项目保留自己的8步、10工具、160000字节和120秒模型循环上限；来源准备预算另计。

本轮没有安装或迁移 Harness、复制其完整历史、引入任意脚本或放宽预算。

## 2. 任务状态与新鲜度

`personal_tasks.previous_task_context`只从当前已授权会话最后一轮提取实际成功查询的领域、规范学期、查询词和模式。记录分页去重，最多6项/10000 UTF-8字节；搜索零命中仍可保留查询意图。失败末轮只接纳其中确实完成的工具，不向更早话题回扫。

任务提示不复制成绩、来源记录、统计值、证据引用、观察编号、PAGE令牌、模型答案或推理。它明确不授予权限、不能复用事实、仍须新来源。查询词作为数据放入system的指代说明，当前唯一user任务优先，不形成旧任务待办。`validate_task_context`对字段、类型、范围、查询及预算进行严格复核。

本人连接代次、模型、thinking、设置修订、出站政策或工具版本变化后不承接旧提示。输入数据版本变化可保留意图，后续事实重新读取；严格本人授权和版本复核仍在每次工具前后执行。工具契约更新为`personal-question-tools-v6-task-continuity`。

这不是完整对话记忆：没有把旧回答提到的任意对象变成可执行状态，也没有跨轮续用分页游标。模糊相对学期、多个候选指代、未取得的正式类别仍需澄清。

## 3. 范围准备及执行前恢复

混合任务先保守识别不同领域的独立时间分句，再沿用原学年/季节解析。不同分句不交叉枚举年份；同领域跨年比较、共享首尾限定和全局6范围上限保留。无可靠年份时不从另一领域猜年份。这是有界语法辅助，不是通用自然语言理解器，模型仍须按当前任务选择工具。

工具schema明确学年连续、成绩/课表的AW/SS、考试单季和主修ALL-HISTORY编码。对已声明工具中仅学期表示格式错误、其余参数均合法的批次，最多让模型修正一次：

1. 全批在执行前拒绝，合法的同批兄弟提议也不先执行。
2. 不发送被拒提议或推理原文，仅给固定格式说明；不由服务端猜替代学期。
3. 拒绝提议计入既有工具预算，修正继续消耗步骤与时间，修正后的调用重新校验和授权。
4. 第二次格式错误终止；未声明工具、额外身份/路径字段、敏感内容、伪造或跨参数PAGE、合法但无权限的范围及其他参数错误仍直接拒绝。

该路径与原有一次最终JSON/引用修复分开，后者仍禁止重跑采集和工具。网络、权限、敏感内容和预算错误不走此自动恢复。

`tool.rejected`是独立真实校验事件，表示未执行的提议。页面显示“工具参数检查”和正在修正/未完成，运行记录不保存参数原文，不计入已返回工具次数。“实际处理记录”涵盖校验与已执行调用，不称为脚本执行或完整内部思维。

## 4. 成绩未知的上游诊断

沿用现有成功业务响应上的安全诊断，补入全部已注册成绩/来源绩点别名。诊断只记录各固定别名在原业务行与白名单投影中的出现数、空值数及类型，不保留原始值、未知键名、身份或凭据。分页聚合与私有持久化沿用原链路；没有新增学校接口或原始HTTP正文日志。

旧回执未覆盖这些字段，不能倒推原接口是否缺值。新读取后的原业务计数、投影计数和解析未知数量需独立核对；别名计数一致也不代表所有未知值的业务原因、正式完成状态或认定已解释。常规模型记录工具尚不投影这些低层诊断，不让模型凭空断言上游原因。

## 5. 历史切换及推荐依赖

历史响应完整且符合当前身份的数据类型后才替换当前会话；网络、服务及无效回执失败保留答案、草稿、重试上下文、手动展开和滚动位置。401仍清理本人状态；旧身份晚到响应不能覆盖新身份。单个依据入口、运行中展开/终态收起、模型选择和thinking按钮保留。

推荐依赖按当前源码分别核实：

| 依赖 | 当前可用 | 尚缺 |
| --- | --- | --- |
| 课程身份 | 本地名称/代码参考及来源版本 | 稳定身份、跨来源映射、当前开课资格 |
| 修读与认定 | 本轮原始成绩、来源学分与未知状态 | 稳定修读实例、重复政策、已获分与认定归属 |
| 培养要求 | 当轮接口取得PDF及局部原文 | 正式本人绑定、适用及规则审核 |
| 教学班 | 本人已读课表的观察时段 | 完整候选班次、稳定班号、余量与资格 |
| 校历/考试 | 已注册查询的原时间观察 | 可执行日期转换、完整周次及冲突输入 |

当前学校注册能力不含完整选课候选/余量/资格/校历接口。本轮不扩采，不把本人课表当全体候选，不解除真实推荐保护。原inputs、候选规则和旧私有证据保留。

## 6. 验证口径

工程回归、实际供应商加合成来源、真实本人调用、有限字段支持、完整语义与用户体验分别记录到开发进度第66节。执行前修正的确定性合成覆盖不冒充供应商实际触发；分句探针不冒充真实混合业务任务验收；基线真实失败不冒充修复后复测。后端正常重启会清理学校内存会话，必须待本人在页面重登才继续新真实取证。


## 7. 待补任务与来源语义补强（v7）

工具契约更新为 `personal-question-tools-v7-source-tasks`。以下是第66节之后的追加实现，不改写前轮验证事实；当轮启用及验证见开发进度第68节。

真实澄清轮保存有界的原请求、最多3次补充、实际澄清问题及可选的上一执行任务提示；仅保存在当前本人会话。它们是未可信的意图文本，不复制工具事实、答案、引用、来源ID或分页令牌。下一轮由模型根据当前消息决定继续补槽或换题；已有待补任务时再次澄清必须明确 `request_basis`，否则只走一次现有格式修复。答复、换题、失败、身份/连接或模型/出站策略变化后不复活更早待办；临时模型失败后的结构化待办恢复仍有待完善，历史用户意图不是可复用事实。超出长度、次数或敏感校验时不保留待补轨迹，不静默截断成另一个任务。

所有教务记录投影附带服务端确定的 `record_source`，区分学期成绩、主修来源、课表和单季考试及范围。成绩概况通过 `source_summary` 选择本轮汇总证据和实际可用统计维度，由服务端组织来源名称、数量、未知、数字简单均值与完成状态字段已知性；模型不能给汇总证据重新命名或改写数字。引用汇总的旧自由文本会进入一次已有答案修复，不能借此重新取数。普通记录、培养说明和推荐解释仍是受限自由文本，引用存在不证明完整语义。

新增 `check_recommendation_inputs`，只在服务预检声明该能力时提供。它复核当前授权、当轮来源回执和本地课程参考元数据，不新增学校请求；分别检查课程推荐及课表推荐的可准备来源与尚未核实的业务依赖。独立P证据通过固定模板和严格状态枚举投影，不接收任意身份、路径、能力提升或自由正文。检查完成不等于推荐可生成；稳定身份、修读认定、本人培养适用、规则审核、当前候选/资格/余量、班次/周次/考试/校历、固定条件及真实冻结导出依赖仍不能据此提升为已核实。原真实推荐保护保留，不新增选退课能力。

页面依据服务端 `task_status` 显示待补信息，保持输入和发送可用；推荐准备检查放在既有单一折叠依据内，实际工具记录显示“推荐输入检查”。运行结束与用户任务完成分开。没有伪造模型思考、终端脚本或推荐结果。


## 8. 真实失败后的推荐准备答复收紧（v8）

v7本人五轮实测中，前四轮取得有限范围支持；第5轮推荐输入检查工具返回成功，模型最终答复却被 `unsupported_personal_claim` 拒绝，整轮失败。没有保留该次最终模型正文，不能认定是误拒或实际越界；原失败回执保留。

随后将工具契约更新为 `personal-question-tools-v8-typed-readiness`：P证据使用 `recommendation_readiness` 结构化结论，模型仅选择本轮证据和必要的来源/依赖/下一步部分，服务端重验固定契约后组织中文。任一展示部分都保留推荐未就绪与生成、保存、导出未开放；不把检查成功说成推荐成功。合法但形状错误的普通P文本可进入原有一次答案修复；敏感内容、越界能力声明仍先行终止，修复无工具，不重复采集。

前端另修复已结束turn被旧running进度覆盖的确定性回落路径，并保留实际收到的推理片段及手动开合。真实现场曾短暂显示终态摘要却仍展开、随后收起，该现象未被证明与此回落路径同源，不冒称根因已确定。v8固定工程与真实复测分别记录到开发进度第68节。
