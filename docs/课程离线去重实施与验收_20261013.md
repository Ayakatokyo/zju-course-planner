## 实施与复跑入口

独立源适配器 [course_source_adapters.py](../scripts/course_source_adapters.py) 从后端持久回执及实际响应、浏览器原采 JSON/HTML 和探索观察读取数据。[deduplicate_courses.py](../scripts/deduplicate_courses.py) 生成课程实体、带上下文的板块关系、候选班次、多个课时片段、完整时段观察、考试和容量时点。个人状态与源定位分别另存。

```sh
python3 scripts/deduplicate_courses.py
python3 scripts/validate_course_dedup.py
python3 -m unittest tests.test_course_dedup -v
```

命令只访问本机文件。输出路径、数据版本和对账结果由命令返回；同一源码和输入版本再次执行必须得到同一目录与字节。新版本使用内容摘要命名，不覆盖旧版本；同名文件内容不同则拒绝写入。真实派生输出只允许位于 `local-only/` 下，文件权限为 0600，新增目录为 0700。

## 归并与保留规则

| 对象 | 本轮键与处理 | 不能推出的结论 |
| --- | --- | --- |
| 课程 | 学校来源主代码体系＋主代码；定义按观测学期分版 | 不按同名/相似度合并；括号代码语义和永久身份未核验 |
| 板块关系 | 课程＋学期＋分类＋完整来源上下文 | 不同或不完整上下文不自动等同；分类不构成方案必修/本人适用 |
| 班次 | 主代码体系＋课程＋学期＋完整来源键 | 仅候选归组，不能当已核验跨刷新官方教学班身份 |
| 多时段 | 每次班行的完整片段序列和位置对齐 | 同课多班、多学期、多段不会统一删掉；缺周次不构造校历 |
| 考试/容量 | 观察 ID＋原观察时间；完整字段包保留 | 不按较晚时间强行消除矛盾；不跨时点拼接快照或称实时余量 |
| 本人页面状态 | 单独受限文件；课程标题与班行分开 | 页面已选/待定/按钮不等于正式中选、获分或本项目本人绑定 |

“最完整”指兼容身份和版本内的字段证据并集：相同已知值关联所有来源，unknown 不覆盖已知，0、false、明确空集合保留。不同已知值保留全部陈述，字段置 conflicting，不用长度、非空数或最后写入挑选。字段并集标为 `field_evidence_union_not_observed_snapshot`；动态记录只返回真实观察包。

共享投影去除 `kcxx` 整串及其中页面状态、原已选/志愿/未核验旗标。课程学分和学时从已核对的编码部分单独解析，原串仍通过受限定位回查。整个派生数据集继续属于 restricted reference；去除个人状态不自动授权匿名开放或生产共享。

后端 `source.filters` 可能是首课请求模板。适配器校验实际 `parent/target.bound_course`、父课程响应行、来源班次键与学期，不仅凭模板 kcdm 判错。浏览器由 HTML 派生的 JSON 不重复计成新观察；停点统计/复盘目录也不作为新的采集来源。历史空响应另保留，不能因此断言学校没有班次。

## 输出与检查口径

- `courses`、`course_observations`、`classification_memberships`：实体、定义与板块关系，保留字段级来源 ID。
- `sections`、`section_observations`、`meetings`、`meeting_snapshots`：候选身份、逐时点班行和完整课时序列；多个观察版本保留。
- `exams`、`capacity_snapshots`：每条班行对应独立考试/容量观察，不给唯一实时值。
- `restricted_personal_page_observations`、`restricted_source_registry`：个人原状态、观察时间、原件哈希、行/DOM定位和筛选上下文。
- `excluded_observations`：用户排除范围的已采片段及原因，原件不删除。
- `conflicts`、`unknowns`、`field_completeness`、`reconciliation`、`manifest`、`delivery_validation`：字段差异、缺口、前后对账和独立重跑证据。

无丢失检查逐项覆盖课程观察映射/明确排除、班次身份集合、每条班行动态包、所有课时片段、原始来源可回查及原件哈希。数量相等仅是其中一项；动态字段另外按原观察 ID 比较完整内容。明细查看保留同一观察的考试、容量和时段，不从静态证据摘要推断当时快照。
