## 启动

基础服务仅需 Python 3.10+，不依赖第三方包；可选本地Embedding使用独立私有编码器运行环境。当前工程在 Python 3.13.13 上验证。

本人教务入口：

```sh
cd /Users/shuzida/Desktop/大数据信息分析系统
python3 -m course_assistant.server --enable-school --port 18875
```

本地课程参考需在启动环境中显式设置`COURSE_CATALOG_DELIVERY_INDEX`为本机已核验的课程交付索引JSON；路径只保留在私有运行配置，不写入仓库。未配置时课程目录工具明确不可用，不影响教务接口取数；该入口只读取课程名称/代码参考，不导入整包培养方案或个人材料。

本学期课程/课表条件测试还需显式设置`COURSE_DATA_TEST_DELIVERY_INDEX`和`COURSE_DATA_TEST_TERM=2026-2027-AW`，并核验已有交付的完整性；普通课程目录配置不会暗中启用历史教学班。该测试不证明学校最新开课、余量或本人正式适用。本地Embedding另需`COURSE_SEMANTIC_ENCODER_MANIFEST`与`COURSE_SEMANTIC_PYTHON`指向已核验的私有编码器运行配置；缺失或失败时明确回退词法。详细准入与边界见[专项设计](docs/本学期推荐闭环与本地语义检索_20261016.md)。

打开 [本人教务登录](http://127.0.0.1:18875/)，在本机页面输入账号和密码；后端按 Celechron 的协议思路向学校验证并持有临时会话。登录后在“我的教务”读取本人资料、成绩、课表、单季考试及对应入学年的培养方案。界面按课表、成绩、考试、资料与培养组织；学年使用本人常用范围下拉，课表按星期/节次展示，成绩支持15条展示分页和已读取记录筛选。主修成绩不按学年或学期筛选，仅展示本次取得的来源记录。验证码需本人输入；学校会话失效时提示重新登录。密码、学校 Cookie 和票据仅在内存中，退出或关闭服务清理，不需要安装扩展或配对。

## 配置 DeepSeek 对话

在项目根目录的 `.env` 填入 `DEEPSEEK_API_KEY`，可参照 [.env.example](.env.example)。文件以点开头，Finder 默认隐藏；不要把 Key 发到聊天、前端或 Git。`DEEPSEEK_MODEL` 默认 `deepseek-flash`，可改为账号实际支持的模型名称。保存后重启上面的服务。程序只解析约定字段，不执行 `.env` 内容。

学校登录后的模型选择位于发送键旁，新登录的 DeepSeek 本人对话默认开启深度思考，输入区左侧按钮可点击关闭/开启，开启时高亮；会话内明确关闭会被保留。目录刷新收在模型下拉菜单末项，从 DeepSeek 官方接口取得账号可用目录，首次仅显示服务端配置值。选择只作用于当前登录会话，立即生效，不改写 `.env`。切换后旧模型上下文重新建立，页面历史保留，下一次提问可直接发送。

回答前的“处理过程”实时显示来源读取、检索和供应商可见推理；模型使用SSE返回推理增量，页面按本人授权轮询有界进度，最终自动补齐本机运行记录。普通模式或供应商未返回推理时明确说明。“运行记录”和处理过程中的“查看完整运行详情”保留耗时、Token用量、错误及格式与引用检查；答案底部只保留“查看依据”。可见推理是供应商提供的输出，不是完整内部思维或正确性证明。诊断保存在本人私有SQLite，常规阶段日志不保存问题全文或检索原文，推理副本有长度限制及凭据/路径脱敏。成绩概况对当前来源全部匹配行计算纯数字成绩的简单均值及分布，独立引用，保留非数字/未知及来源覆盖，不称GPA或已获学分。身份介绍、问候等使用模型选择的受限说明，不强求个人资料引用。对话区独立上下滚动，底部输入区保持可用，支持上翻、下翻及回到最新消息。

原合成推荐/参考工具的 `COURSE_ALLOW_REFERENCE_TEXT=false` 默认只在本机显示培养方案引用；该分支模型收不到原文。仅在明确允许必要非个人片段发给 DeepSeek 时设为 `true`。该设置不授权外传真实个人材料。学校本人对话按用户授权默认随提交发送本轮问题、相关已读记录的允许字段及必要培养片段；请求仍携带个人策略版本，凭据、完整PDF和本机来源标识不进入模型，不接受任意文件直接作为已验证本人输入。

配置后可执行独立验证：`python3 validation/run_live_chat.py`。它会实际调用 API，在临时合成工作区测试查询、推荐、继承锁定调整与参考检索；会话与回执保存在 Git 忽略的 `local-only/chat_acceptance/`。它与浏览器、学校真实业务验收分开。[本轮系统与对话设计](docs/系统与对话查询实施设计_v1.md)列出完整模块、接口、范围和依赖。

## 已实现的本机范围

以下P0/P1、冻结和导出描述通用计算与合成演示底座；本人分支只在实际来源和已开放契约内使用，不表示正式推荐、本人保存或导出已经开放。

- Agent 对话默认入口、DeepSeek 服务端适配、本人多轮会话、受限查询/确定性预览/参考检索工具。模型需配置后才发送；最终结论和引用按真实工具结果核验，再由程序呈现事实摘要。退出、会话失效或主体变化清空页面对话。真实模型已在固定合成问题上验证查询、推荐与连续调整；对话不直接修改工作区或自动选课。
- 每次个人请求验证服务端会话和有效绑定；会话轮换、退出、空闲/绝对到期；写接口验证 CSRF、Origin 和 Host。知道他人学号或方案编号不获得权限。工作区、偏好、保存、比较、重新校验和导出按 owner 与安全域查询；活动及冻结输入另核对内部归属、synthetic 属性和摘要。
- P0 保留修读实例、课程身份和认定归属；实际获分与条件覆盖分开。失败、在修、待认定、被替代和未知不算已获学分。同码多次通过缺适用重复政策时保留 unknown，不统一折叠。学分使用 Decimal；需要原始小数精度时输入十进制字符串。
- P1 检查专业/方案版本、明确资格、先修、余量、学期、周集合、分学期、多时段、考试及固定安排。缺班号、时段、考试或校历保留 unknown。负余量是已知不可用，零与未知分开。最多展示三个组合，比较使用相同当前输入重新计算。
- 调整保留锁定、预置、正式来源成员和固定项，使用偏好版本防止旧条件覆盖。解除个人锁须明确指定；不会解除预置/正式安排。缺失班次不会默认为空闲，无解与待确认状态分别显示。
- 保存版本冻结数据、规则、偏好和校验。查看历史保持只读；“按当前数据重新校验”继承当前偏好与当前/历史锁定，产生当前草案，不改历史。历史比较保留各自输入，不将不同版本视为同条件排名。
- JSON、CSV、ICS 保留 synthetic、来源、冻结版本、未知/冲突及草案状态。ICS 仅导出显式校历映射的已知课时、固定安排和已知考试；无可靠校历正常拒绝。保存或导出不表示正式中选或已获学分。

演示账本基础 8、课堂 4、在修 3、未知记录 1；演示规则独立于原 23 条待审核候选。原资料模式没有本人学业数据，不输出真实毕业或资格结论。开发者 JSON 入口只接受当前固定合成学生的数据；结构校验不能独立证明任意自由文本的真实性。
