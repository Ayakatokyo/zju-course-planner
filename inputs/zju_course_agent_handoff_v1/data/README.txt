选课助手数据样本 v1
制作日期：2026-10-09

用途
供“培养方案检索 + 规则检查 + 对话选课助手”课程项目进行初步数据建模与人工审阅。这是数据样本包，不是系统实现，不含可运行的Agent、学校API封装或个人选课操作。

本包包含
1. plan_registry.json：3份2026级培养方案元数据、模块学分、来源文件SHA256与PDF物理页码。
2. course_samples.json：19条真实课程样本（商务12、材料4、新闻3）；不是全量课程目录。
3. requirement_candidates.json：23条候选要求（商务15、材料4、新闻4）；不是完整毕业审核规则。
4. source_issues.json：12项来源差异及待补证据，含新闻学15/16学分差异、课程性质差异及缺少的适用政策。
5. import_data_dictionary.json：11类实体的拟议字段，包括Course、Section、Meeting、AcademicRecord、CurriculumRequirement、StudentProfile、Preference、Snapshot、Recommendation、WishGroup、WishItem。字段是本项目设计，不冒充学校API。
6. offering_snapshot_template.json：空的真实开课导入模板。status=awaiting_import，available_count=0，records=[]。
7. README.txt：本说明。

来源范围
新闻学：document-3.pdf，2026级，最低毕业学分138+8。
材料科学与工程：document-2.pdf，2026级，最低毕业学分149+8。
商务大数据分析（信息管理与信息系统-统计学）：document (1).pdf，2026级，最低毕业学分168+8。
三份方案的+8均按第二课堂4、第三课堂2、第四课堂2分列。
原始PDF未重复打包；请与已有上传文件一并保留，文件哈希可用于核对版本。页码均为PDF物理页码，从1开始。

必须保留的区别
真实培养方案课程不等于当前学期开设的教学班。建议学年学期不是具体星期、节次或保证开课；修读示意图中的先后位置也不是已确认的强制先修关系。
本包当前实际教学班数量为0，没有编造教师、周次、校区、容量、余量或当前学期。因缺少这些数据，不能据此直接生成可提交的正式选课结果。
上传文件并不等于已确认当前官方生效版本，也不代表已确认适用于当前学生。须另行确认入学年级、专业/项目、培养方案版本、专业方向、个性修读路径及外语层次。
所有23条培养要求均为候选、需要人工审核、禁止自动执行。应经教务或项目规则审核后形成正式版本。源文件差异保留证据，不直接判为错误。
学分、学时、记点、课程门数分别处理。课程可同时满足不同标签或门数要求，但不能凭此重复计算实际总学分。认定型要求不机械叠加到“基础学分+8”。

两项明确待确认
新闻学第7页“个性修读课程15学分”与“本专业进阶模块16学分”有差异，可能涉及路径或课程组合要求；本包保留两个数字并将实际阈值待确认，不擅自改成15或16。
新闻学CS1243G在第4页列于通识必修计算机类，在第10页指导性计划标为选修；本包保留两处证据，未自行裁定课程性质。

志愿与正式课表
字段设计参考浙江大学公开《选课操作手册》第6页与第8页，区分志愿组、备选教学班排序、已选上与待定。备选志愿并不意味着组内所有教学班都会同时进入正式课表，不能把所有备选项当已选课混算冲突。归一状态是拟议设计，必须保留真实页面状态并验证映射。
手册资料来源：https://zdbk.zju.edu.cn/jwglxt/zjdxFilemgr/file_download.html?uid=569CF3B93BFFD98CE0632AB3CA0A55C6

数据与隐私范围
本包不含个人身份信息、真实成绩、个人学业记录、密码、Cookie、带身份或会话参数的链接。StudentProfile、AcademicRecord及Recommendation只有字段定义，没有实例。
所有JSON均使用UTF-8；未提供事实使用null或unknown，实际余量0与未知值必须区分。

交付前结构性核对
JSON可解析；3个培养方案ID、19个课程样本ID和课程ID、23个规则ID、12个问题ID、11个实体名均唯一；课程号、名称、学分、建议学年学期和PDF物理页已核对。四主模块数字分别加总为168、149、138，+8分账为4+2+2。
本项核对用于验证样本提取与结构，不等同于校方规则审核、实时开课核验或完整系统测试。
