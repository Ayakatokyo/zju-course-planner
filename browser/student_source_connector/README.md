# 本机学生来源连接器

这是独立 `restricted_personal_reference` 采集入口的 Chrome MV3 连接器，不挂主应用模拟身份、推荐工具或模型。学校凭据只在官方登录页输入。扩展不读取或导出 Cookie，不申请 `cookies`、`storage`、`scripting` 权限；本机连接令牌只存在扩展 worker 内存中。

## 首次使用

1. Chrome 打开 `chrome://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，加载本目录。扩展不包含任何个人数据或预置会话。
2. 启动独立本机 broker，具体 CLI 参数见本轮项目交接。配对成功后服务只接受该次配对的扩展 Origin，严格绑定 `127.0.0.1`。
3. 在 `https://zdbk.zju.edu.cn/` 官方页完成登录、验证码及必要的个人确认。安装扩展前已打开的页面须重载一次；扩展源码变化后，由使用者在扩展管理页重新加载，再重载官方来源页。
4. 进入成绩、主修成绩、课表、考试或培养方案目录页，选择所需范围。切回官方页打开扩展弹窗，选择对应来源并点“确认当前来源页”。固定请求路由必须在当前路径或页面实际链接/表单中出现；没有实际来源证据时停止。
5. 点“打开本机连接页”，从本机页面复制一次性连接码。回到刚才的官方标签，打开扩展弹窗，填码并连接。连接码和令牌不用发送给助手，不进入 CLI 参数或日志。
6. 由本机任务发起有限查询。扩展使用官方同源 `fetch` 和浏览器已有会话，返回白名单业务字段；不是再逐行截图。成绩、主修成绩、课表和考试保持独立操作。

当前连接固定于一个标签及内容脚本实例。页面重载或导航销毁内容脚本后，旧 epoch 无效，需重新确认并连接；断开、标签关闭或 epoch 变化会尽力通知 broker 撤销配对。内容实例每 5 秒通过 worker 发送心跳，即使业务请求仍在执行也检查连接；worker 被 Chrome 回收后内存令牌消失，由 broker 心跳超时撤销，随后需重新连接。不会自动重登、保存密码、绕过验证码或代点个人承诺。

## 范围和失败行为

- 每次请求 30 秒，JSON 最大 2 MiB，PDF 最大 10 MiB；每页默认 20 条，最多 3 页。扩展无自动重试；串行任务、临时传输重试及缓存由 Python 客户端控制。
- 学年、学期读取当前官方筛选控件的实际值；不将源码里的单季编码猜成秋冬。当前页无法确认目标范围时返回 `route_not_confirmed`。
- 成绩页已观察到隐藏的 `xn_cx` / `xq_cx` SELECT 和同级 Chosen 控件：只有可见 Chosen 标签与唯一选中 option 一致时读取。成绩 POST 参数按实际公开来源 JS 映射为 `xn` / `xq`；其他域分开核对。仅复制当前页已观察的 `gnmkdm=N…` 菜单码，不复制 `su` 或个人查询标识。响应明示选课课号中的学年与目标学年冲突时拒绝，不把错误筛选出的历史成绩当当期数据。
- 课表登记支持实际菜单页面 `/jwglxt/kbcx/xskbcx_cxXskbcxIndex.html`，查询仍固定到独立 `/jwglxt/kbcx/xskbcx_cxXsKb.html`；`xnm/xqm/xqmmc` 来自当前已确认控件，秋、冬等单季与秋冬组合分开核对，不造默认组合码。仅当可见表格／列表按钮恰有一个处于选中状态，才按已确认来源 JS 映射 `xxqf/xsfs=0/0` 或 `1/1`。表格响应出现尚未支持的实践等补充列表时停止，避免漏掉这些记录；本轮实际入口采用列表视图。
- 考试页使用已观察的 `xnSelect` / `xxqSelect` 控件，并按公开来源 JS 将明确的单季 `1|秋` 等值变为 `xxq` 和 `xnxq` 筛选，不发送空默认查询。`kssj/jsmc` 与 `qzkssj/qzjsmc` 分别保留期末和期中原值，空值保留；`xm` 不用于来源身份。
- 401、403、登录跳转、验证码及承诺弹窗只回传状态，失败不回传正文。凭据字段被剥离，业务值中出现凭据特征则整个响应拒绝。未知 Schema 停止，不用默认值补齐。
- 培养方案优先使用已确认的官方目录接口。`synj_cx/xydm_cx/zydm_cx` 的实际选中值构成查询，学院／专业的可见标签与本人范围逐字核对。仅映射响应中的 `xymc/zymc/jxjhh` 必要字段；目录行不提供入学年，`cohort` 来自已确认查询年级，并附 `cohort_provenance=confirmed_query_scope`，不会从方案号推年级。原档案只有类专业名称时，可与目录明确专业名称作字面筛选，输出保留各自来源字段，映射仍待核验。未知标题、项目、路径和总数保持未知；分页仍受三页预算约束。旧的明确表头／筛选标签 DOM 适配保留为回退观察，限当前一页。目录结果不能建立本人适用绑定。
- PDF 下载使用目录响应中已观察的方案号，通过随机 `plan_ref` 引用同一范围下固定官方资源 `/jwglxt/pyfagl/pyfayl_cxPyfaylPdf.html?id=…&doType=query`；该 `.html` 资源映射由实际预览和公开来源 JS 确认，不接受其他 HTML 地址、任意 ID 或 `su`。通用 DOM 回退仅登记实际可见的同源 `.pdf` 直链。换范围或页面实例后引用失效；返回 MIME 和 `%PDF-` 签名均核验后才送本机保存。
- 不请求课程更新、选退课、认证、第三方域名或任意 URL，也不接受学号作为查询条件。响应中的显式业务学号仅用于本人来源连续性；它不是正式学校认证结果。

## 工程验证

`python3 -m unittest discover -s tests -p test_student_connector.py -v` 在 Node 中执行纯核心合成测试，不读取真实资料或访问学校；四份 JS 可用 `node --check` 检查。实际 Chrome 扩展安装、学校接口及培养目录列映射另行验收，不能由这些测试代替。

参考 Celechron 固定源码提交 `724e54a3d8feb190a90544963cd53e8ef01c0ff9` 的分域读取与会话失败处理设计；本目录为本项目独立实现，未复制其密码认证、账号片段推年级、自动默认值或第三方日期推算。
